## 凉菜

### 醋泡花生米

| 主料   |
| :----- | ----: |
| 花生米 | 250克 |

| 料汁 |
| :--- | ----: |
| 陈醋 | 150克 |
| 香醋 |  60克 |
| 白糖 |  30克 |
| 生抽 |  50克 |

| 香料   |
| :----- | ---: |
| 八角   |  5克 |
| 香叶   |  2克 |
| 干辣椒 |  3克 |
| 桂皮   |  1克 |

| 辅料   |
| :----- | ---: |
| 胡萝卜 |  1根 |
| 芹菜   |  1根 |
| 生姜   |  5克 |
| 小米辣 | 适量 |
| 大蒜   | 适量 |

制作过程：  
1、花生米冷水下锅，加入香料和盐，水开后捞出  
2、加入适量煮花生米的原汤，浸泡至放凉  
3、生姜切片，锅中加入两种醋，小火烧开，再加入姜片、生抽和白糖搅拌均匀，盛出后放凉  
4、胡萝卜、芹菜斜刀切段，芹菜焯水，大蒜切片  
5、花生米沥干水分，加入辅料，倒入醋汁，浸泡1小时以上

### 老醋蜇头

| 辅料 |
| :--- | ---: |
| 大蒜 | 10克 |
| 香菜 | 10克 |

| 料汁 |
| :--- | ---: |
| 陈醋 | 30克 |
| 香醋 | 10克 |
| 生抽 | 10克 |
| 白糖 | 15克 |
| 香油 |  5克 |

制作过程：  
1、海蜇冲洗干净，浸泡30分钟后捞出，挤干水分  
2、黄瓜拍散后切块，大蒜切末，香菜切段  
3、将陈醋、香醋、生抽和白糖混合均匀

5、加入香油和香菜，拌匀后冷藏10分钟，装盘

P.S.  
1、海蜇拌制前应充分挤干，避免析出的水分稀释料汁

### 烟熏三文鱼塔塔

| 主料       |
| :--------- | ----: |
| 烟熏三文鱼 | 150克 |
| 牛油果     |   1个 |
| 鱼子酱     |  20克 |

| 辅料       |
| :--------- | ---: |
| 红葱头     | 15克 |
| 醋渍刺山柑 | 10克 |
| 莳萝       |  2克 |

| 调料     |
| :------- | ---: |
| 柠檬汁   | 10克 |
| 橄榄油   | 10克 |
| 黑胡椒碎 | 适量 |

制作过程：  
1、三文鱼切成小丁，红葱头和莳萝分别切碎，刺山柑沥干后切碎  
2、牛油果去皮去核后切成小丁，加入5克柠檬汁轻轻拌匀  
3、三文鱼加入红葱头、刺山柑、莳萝、剩余的柠檬汁、橄榄油和黑胡椒碎，轻轻拌匀  
4、将模具放在盘中，先放入牛油果丁并轻轻压平，再放入拌好的三文鱼，轻轻压实并整平表面  
5、脱模后放上鱼子酱

P.S.  
1、鱼子酱应在脱模后加入，避免挤压破坏颗粒和口感

## 素菜

### 柏合豆腐皮

| 主料   |
| :----- | ----: |
| 豆腐皮 | 200克 |

| 辅料   |
| :----- | ---: |
| 猪肉末 | 50克 |
| 蒜苗   | 30克 |
| 大蒜   | 10克 |
| 生姜   |  5克 |
| 豆豉   | 10克 |

| 调料       |
| :--------- | ----: |
| 郫县豆瓣酱 |  30克 |
| 辣椒粉     |  10克 |
| 花椒粉     |   2克 |
| 生抽       |  10克 |
| 味精       |   2克 |
| 高汤       | 300克 |

制作过程：  
1、豆腐皮卷起后切成尽可能细的丝，大蒜和生姜切末，蒜苗切花  
2、锅中烧水，放入豆腐皮煮3分钟，捞出后用清水冲凉并沥干水分  
3、锅中加入油，烧热后放入猪肉末，煸炒至酥香  
4、加入姜末、蒜末、豆瓣酱和豆豉，小火炒香并炒出红油  
5、加入辣椒粉炒香，倒入高汤，加入生抽和味精烧开  
6、放入豆腐皮，小火煮3分钟，使其充分吸收汤汁  
7、将水淀粉分三次沿锅边淋入，每次轻轻推动豆腐皮，待芡汁收紧后再加入下一次  
8、待汤汁浓稠并完全附着在豆腐皮上，加入一半蒜苗和花椒粉，轻轻推匀  
9、盛入碗中，撒上剩余的蒜苗后食用

### 包菜炒粉丝

| 主料 |
| :--- | ----: |
| 包菜 | 300克 |
| 粉丝 |  80克 |
| 鸡蛋 |   2个 |

| 辅料   |
| :----- | ---: |
| 大蒜   | 10克 |
| 小米辣 | 10克 |
| 小葱   | 10克 |

| 调料 |
| :--- | ---: |
| 生抽 | 10克 |
| 老抽 |  2克 |
| 白糖 |  3克 |
| 盐   |  3克 |
| 香醋 |  5克 |
| 清水 | 10克 |

制作过程：  
1、包菜去芯后切丝，粉丝泡软后剪短，加入老抽和适量油拌匀  
2、大蒜切末，小米辣切段，小葱切花，鸡蛋加入清水搅散

4、锅中加入适量油，放入蒜末和小米辣爆香，再放入包菜，大火炒至断生  
5、加入生抽、白糖和盐，放入鸡蛋和粉丝，翻炒至粉丝吸收汤汁

### 豆豉鲮鱼油麦菜

| :----- | ----: |

| 辅料         |
| :----------- | ----: |

### 黄油煎松茸

| 主料 |
| :--- | ----: |
| 松茸 | 200克 |

| 调料     |
| :------- | ----: |
| 黄油     |  20克 |
| 盐       |   2克 |
| 黑胡椒碎 | 0.5克 |

制作过程：  
1、松茸削去根部泥土，用湿布擦拭干净后纵向切成约5毫米厚的片

4、翻面继续煎1～2分钟，煎至两面金黄、边缘微焦  
5、撒上盐和黑胡椒碎，翻拌均匀后出锅

| :------- | ----: |

| 辅料 |
| :--- | ---: |

| 红椒 | 50克 |

| :------- | ---: |
| 土豆淀粉 | 30克 |

制作过程：

### 麻婆豆腐

| 主料   |
| :----- | ----: |
| 豆腐   | 400克 |
| 牛肉末 |  50克 |

| 料头 |
| :--- | ---: |
| 泡姜 | 15克 |
| 泡椒 | 20克 |
| 蒜苗 | 20克 |

| 调料       |
| :--------- | ----: |
| 郫县豆瓣酱 |  20克 |
| 豆豉       |  10克 |
| 刀口辣椒   |   8克 |
| 花椒粉     |   2克 |
| 生抽       |  10克 |
| 老抽       |   3克 |
| 白糖       |   2克 |
| 盐         |   1克 |
| 清水       | 300克 |

制作过程：  
1、豆腐切成约1.2厘米的块，泡姜和泡椒切末，蒜苗切碎  
2、锅中加入清水和少许盐，将豆腐放入，烧开后煮1分钟，捞出沥干  
3、锅中加入适量油和猪油，放入牛肉末，中小火炒干炒香  
4、加入豆瓣酱、豆豉、泡姜和泡椒，小火炒出红油，再加入5克刀口辣椒翻炒均匀  
5、加入清水、生抽、老抽、白糖和盐，烧开后放入豆腐，小火烧5分钟  
6、将水淀粉分三次加入，每次轻轻推动豆腐，待芡汁收紧后再加入下一次  
7、加入适量明油轻轻推匀后出锅，撒上剩余的刀口辣椒、花椒粉和蒜苗

P.S.  
1、豆腐不限种类，老豆腐香味更足，嫩豆腐口感更细腻  
2、三次芡应一次比一次浓、用量一次比一次少

### 奶油菠菜泥

| 主料   |
| :----- | ----: |
| 菠菜   | 300克 |
| 淡奶油 |  80克 |
| 牛奶   |  50克 |

| 辅料   |
| :----- | ---: |
| 黄油   | 15克 |
| 黄洋葱 | 30克 |
| 大蒜   |  5克 |
| 面粉   |  5克 |

| 调料     |
| :------- | ----: |
| 盐       |   2克 |
| 白胡椒粉 | 0.3克 |
| 肉豆蔻粉 | 0.1克 |

制作过程：  
1、菠菜清洗干净，放入沸水中焯水30秒，捞出过凉后挤干水分  
2、菠菜切碎，加入牛奶搅打成菠菜泥  
3、洋葱和大蒜切末  
4、锅中加入黄油，小火融化后放入洋葱末和蒜末，炒至洋葱变软  
5、加入面粉，小火翻炒1分钟  
6、倒入菠菜泥和淡奶油，搅拌均匀后小火煮至浓稠  
7、加入盐、白胡椒粉和肉豆蔻粉，搅拌均匀后出锅

P.S.  
1、菠菜焯水后应充分挤干，避免成品水分过多  
2、搅打时间不宜过长，保留少量菠菜颗粒口感更丰富
