---
title: "油泼豆芽"
---

| 主料   |
| :----- | ----: |
| 绿豆芽 | 300克 |

| 辅料   |
| :----- | ---: |
| 大蒜   | 10克 |
| 小葱   | 10克 |
| 干辣椒 |  3克 |
| 花椒   |  1克 |

| 调料 |
| :--- | ---: |
| 生抽 | 10克 |
| 香醋 | 15克 |
| 白糖 |  3克 |
| 盐   |  1克 |

制作过程：  
1、豆芽洗净，大蒜切末，小葱切花，干辣椒切段  
2、锅中烧水，水开后放入豆芽煮熟，捞出过凉，充分沥干水分  
3、豆芽中加入生抽、香醋、白糖和盐，翻拌均匀  
4、将蒜末、葱花和干辣椒放在豆芽表面  
5、锅中加入适量油和花椒，小火炸香后捞出花椒，将热油淋在蒜末、葱花和干辣椒上  
6、翻拌均匀后装盘
