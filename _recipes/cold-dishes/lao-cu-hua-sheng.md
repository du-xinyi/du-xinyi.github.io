---
title: "老醋花生"
---

| 主料   |
| :----- | ----: |
| 花生米 | 250克 |

| 辅料   |
| :----- | ---: |
| 紫洋葱 | 50克 |
| 青椒   | 30克 |
| 红椒   | 30克 |

| 料汁 |
| :--- | ---: |
| 陈醋 | 70克 |
| 香醋 | 20克 |
| 冰糖 | 55克 |
| 生抽 | 25克 |
| 蚝油 | 15克 |

| 香料   |
| :----- | ----: |
| 生姜   |   3克 |
| 八角   |  半个 |
| 香叶   |   1片 |
| 花椒   | 0.5克 |
| 香菜梗 |   5克 |

制作过程：  
1、洋葱、青椒和红椒切成小块，生姜切片  
2、锅中加入适量油，放入花生米，小火慢炸至颜色微黄、响声变轻，捞出沥油后充分放凉  
3、锅中加入料汁和香料，小火加热至冰糖完全溶解  
4、继续小火煮3分钟，过滤掉香料，将料汁充分放凉  
5、花生米中加入洋葱、青椒和红椒，倒入全部料汁  
6、快速翻拌均匀后装盘
