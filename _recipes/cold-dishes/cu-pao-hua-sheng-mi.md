---
title: "醋泡花生米"
---

| 主料   |
| :----- | ----: |
| 花生米 | 250克 |

| 料汁 |
| :--- | ----: |
| 陈醋 | 150克 |
| 香醋 |  60克 |
| 白糖 |  30克 |
| 生抽 |  50克 |

| 香料   |
| :----- | ---: |
| 八角   |  5克 |
| 香叶   |  2克 |
| 干辣椒 |  3克 |
| 桂皮   |  1克 |

| 辅料   |
| :----- | ---: |
| 胡萝卜 |  1根 |
| 芹菜   |  1根 |
| 生姜   |  5克 |
| 小米辣 | 适量 |
| 大蒜   | 适量 |

制作过程：  
1、花生米冷水下锅，加入香料和盐，水开后捞出  
2、加入适量煮花生米的原汤，浸泡至放凉  
3、生姜切片，锅中加入两种醋，小火烧开，再加入姜片、生抽和白糖搅拌均匀，盛出后放凉  
4、胡萝卜、芹菜斜刀切段，芹菜焯水，大蒜切片  
5、花生米沥干水分，加入辅料，倒入醋汁，浸泡1小时以上
