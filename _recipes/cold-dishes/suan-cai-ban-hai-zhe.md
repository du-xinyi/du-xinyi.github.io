---
title: "酸菜拌海蜇"
---

| 主料   |
| :----- | ----: |
| 酸芥菜 | 150克 |
| 海蜇   | 250克 |

| 辅料 |
| :--- | ---: |
| 大蒜 | 10克 |
| 香菜 | 10克 |

| 料汁 |
| :--- | ---: |
| 白糖 | 10克 |
| 红油 | 10克 |
| 香油 |  5克 |

制作过程：  
1、海蜇冲洗干净，浸泡30分钟后捞出，挤干水分  
2、酸菜冲洗干净，挤干水分后切丝  
3、大蒜切末，香菜切段，料汁混合均匀  
4、酸菜和海蜇中加入蒜末与料汁，翻拌均匀  
5、加入香菜，拌匀后冷藏10分钟，装盘
