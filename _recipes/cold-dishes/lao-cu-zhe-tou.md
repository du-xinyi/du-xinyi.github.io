---
title: "老醋蜇头"
---

| 主料 |
| :--- | ----: |
| 海蜇 | 300克 |
| 黄瓜 | 150克 |

| 辅料 |
| :--- | ---: |
| 大蒜 | 10克 |
| 香菜 | 10克 |

| 料汁 |
| :--- | ---: |
| 陈醋 | 30克 |
| 香醋 | 10克 |
| 生抽 | 15克 |
| 盐   |  1克 |
| 白糖 | 15克 |
| 香油 |  5克 |

制作过程：  
1、海蜇冲洗干净，浸泡30分钟后捞出，挤干水分  
2、黄瓜拍散后切块，大蒜切末，香菜切段  
3、将陈醋、香醋、生抽、白糖和盐混合均匀  
4、海蜇和黄瓜中加入蒜末与料汁，翻拌均匀  
5、加入香油和香菜，拌匀后冷藏10分钟，装盘

P.S.  
1、海蜇拌制前应充分挤干，避免析出的水分稀释料汁
