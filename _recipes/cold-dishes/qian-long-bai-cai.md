---
title: "乾隆白菜"
---

| 主料   |
| :----- | ---: |
| 白菜心 | 一个 |

| 酱料   |
| :----- | ---: |
| 芝麻酱 | 10克 |
| 白糖   | 15克 |
| 盐     |  1克 |
| 老抽   |  2克 |
| 生抽   |  3克 |
| 陈醋   | 15克 |
| 蜂蜜   |  5克 |
| 香油   | 适量 |

| 辅料     |
| :------- | ---: |
| 熟白芝麻 | 适量 |

制作过程：  
1、菜心洗净后撕成大块，控干水分  
2、酱料混合均匀后加入凉白开调成稀糊状  
3、将白菜和酱料混合均匀后撒上熟芝麻
