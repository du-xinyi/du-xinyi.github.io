---
title: "乾隆白菜"
---

| 主料   |
| :----- | ----: |
| 白菜心 | 500克 |

| 酱料   |
| :----- | ---: |
| 芝麻酱 | 30克 |
| 白糖   | 35克 |
| 盐     |  5克 |
| 老抽   |  5克 |
| 生抽   | 10克 |
| 香醋   | 45克 |
| 蜂蜜   | 20克 |
| 香油   | 适量 |
| 凉白开 | 适量 |

| 辅料     |
| :------- | ---: |
| 熟白芝麻 | 适量 |

制作过程：  
1、菜心洗净后撕成大块，控干水分  
2、酱料中除凉白开外的材料混合均匀，再分次加入凉白开，调成稀糊状  
3、将白菜和酱料混合均匀后撒上熟芝麻
