---
title: "可乐复合香料"
---

| 主料           |
| :------------- | ----: |
| 干甜橙皮       |  10克 |
| 锡兰肉桂       |   8克 |
| 干柠檬皮       |   5克 |
| 绿豆蔻（带壳） |   4克 |
| 肉豆蔻         | 1.5克 |
| 干香草荚       |   1克 |
| 丁香           | 0.5克 |

制作过程：  
1、橙皮和柠檬皮剪小，肉桂掰碎，绿豆蔻拍开，肉豆蔻粗压碎，香草荚剖开后剪段，丁香保持整粒  
2、所有香料混合均匀，装入密封容器，避光防潮保存
