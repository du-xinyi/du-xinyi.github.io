---
title: "麻辣干碟"
---

| 主料   |
| :----- | ----: |
| 干辣椒 | 500克 |
| 红花椒 |  25克 |
| 花生   | 100克 |
| 黄豆   | 100克 |
| 盐     |  55克 |
| 八角   |   3克 |
| 山奈   |   3克 |
| 香叶   |   3克 |
| 桂皮   |   2克 |
| 陈皮   |   3克 |
| 孜然粒 |  10克 |

| 辅料     |
| :------- | ---: |
| 熟白芝麻 | 30克 |
| 白糖     | 10克 |

制作过程：  
1、小火加入盐、花生和黄豆，将花生和黄豆炒熟后加入其余主料  
2、小火翻炒至香料出味后将盐和其余主料筛离  
3、冷却后将主料打成粉末，与炒过的盐，辅料混合均匀
