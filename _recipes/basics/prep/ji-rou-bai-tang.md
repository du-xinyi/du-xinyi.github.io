---
title: "鸡肉白汤"
---

| 主料 |
| :--- | -----: |
| 鸡架 | 1500克 |
| 鸡爪 |  300克 |
| 清水 | 3500克 |

| 辅料 |
| :--- | ---: |
| 生姜 | 20克 |
| 小葱 | 20克 |

制作过程：  
1、鸡架清理干净，去掉残留内脏，剁成大块，鸡爪剪去指甲，生姜拍破，小葱打结  
2、鸡架和鸡爪冷水下锅，烧开后煮5分钟，捞出冲洗干净  
3、锅中加入清水、鸡架、鸡爪、生姜和葱结，大火烧开后撇去浮沫  
4、保持中大火煮2小时，使汤汁持续翻滚，水量不足时补适量开水，保持骨料浸在汤中，煮至汤色乳白  
5、过滤掉鸡架、鸡爪和葱姜，冷却后分装冷藏或冷冻保存
