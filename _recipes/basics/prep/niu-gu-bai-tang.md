---
title: "牛骨白汤"
---

| 主料   |
| :----- | -----: |
| 牛棒骨 | 1500克 |
| 牛腩   |  300克 |
| 清水   | 4000克 |

| 辅料 |
| :--- | ---: |
| 生姜 | 25克 |
| 大葱 | 30克 |

制作过程：  
1、牛棒骨敲开，与牛腩一起用清水浸泡2小时，其间换水，牛腩切块，生姜拍破，大葱切段  
2、牛棒骨和牛腩冷水下锅，烧开后煮10分钟，捞出冲洗干净  
3、锅中加入清水、牛棒骨、牛腩、生姜和葱段，大火烧开后撇去浮沫  
4、保持中大火煮4小时，使汤汁持续翻滚，水量不足时补适量开水，保持骨料浸在汤中，煮至汤色乳白  
5、过滤掉骨肉和葱姜，冷却后分装冷藏或冷冻保存
