---
title: "明油"
---

| 主料   |
| :----- | ----: |
| 菜籽油 | 500克 |

| 香料 |
| :--- | ----------: |
| 八角 |         8克 |
| 桂皮 |        10克 |
| 山奈 |         2克 |
| 香叶 |         2克 |
| 草果 | 1颗（敲碎） |

| 辅料   |
| :----- | ---: |
| 生姜   | 15克 |
| 紫洋葱 | 60克 |
| 小葱   | 15克 |
| 大葱   | 20克 |
| 香菜   | 15克 |

制作过程：  
1、生姜切片，洋葱切丝，小葱、大葱、香菜切段  
2、锅中加入油，烧至5成热，转小火加入香料和辅料  
3、熬至葱姜成金黄色后捞出料渣
