---
title: "牛肉清汤"
---

| 主料 |
| :--- | -----: |
| 牛骨 | 1000克 |
| 牛腩 |  500克 |
| 清水 | 4000克 |

| 辅料 |
| :--- | ---: |
| 生姜 | 20克 |
| 大葱 | 30克 |

制作过程：  
1、牛骨敲开，与牛腩一起用清水浸泡2小时，其间换水，牛腩切块，生姜拍破，大葱切段  
2、牛骨和牛腩冷水下锅，烧开后煮5分钟，捞出冲洗干净  
3、锅中加入清水、牛骨、牛腩、生姜和葱段，烧开后撇去浮沫  
4、转小火，保持微沸，锅盖留缝煮3小时，其间避免搅动，水量不足时补适量开水  
5、过滤掉骨肉和葱姜，撇去浮油，冷却后分装冷藏或冷冻保存
