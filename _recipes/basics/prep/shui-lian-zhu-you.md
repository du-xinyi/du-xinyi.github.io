---
title: "水炼猪油"
---

| 主料   |
| :----- | -----: |
| 猪板油 | 1000克 |

| 辅料 |
| :--- | ---: |
| 生姜 | 10克 |
| 花椒 |  2克 |

| 调料 |
| :--- | ----: |
| 清水 | 500克 |
| 白酒 |  10克 |
| 白醋 |   3克 |

制作过程：  
1、猪板油切成小丁  
2、猪板油冷水下锅，加入白酒，水微开后捞出冲洗干净  
3、锅中加入清水，放入猪板油、生姜和花椒，小火加热  
4、其间不断翻动，直至水分基本蒸发并开始出油  
5、加入白醋，继续小火熬至油渣金黄  
6、捞出油渣和辅料，趁热过滤猪油，放凉后密封保存
