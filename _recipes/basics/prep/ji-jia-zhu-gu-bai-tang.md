---
title: "鸡架猪骨白汤"
---

| 主料   |
| :----- | -----: |
| 清水   |  5千克 |
| 鸡架   | 1000克 |
| 猪棒骨 | 1000克 |

| 辅料 |
| :--- | ---: |
| 生姜 | 20克 |

制作过程：  
1、鸡架和敲裂的猪棒骨用清水浸泡1小时，冲洗干净后冷水下锅  
2、水开后煮5分钟，撇去浮沫，捞出骨料冲洗干净  
3、锅中加入清水，放入骨料和拍破的生姜，大火烧开  
4、撇去浮沫后保持大火熬煮30分钟，转中大火继续熬煮2小时，水量不足时补适量开水，保持骨料浸在汤中，使汤色浓白  
5、过滤掉骨料和生姜，放凉后分装保存
