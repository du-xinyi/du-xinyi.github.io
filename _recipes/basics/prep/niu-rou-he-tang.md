---
title: "牛肉褐汤"
---

| 主料 |
| :--- | -----: |
| 牛骨 | 1000克 |
| 牛腩 |  300克 |
| 清水 | 3000克 |

| 辅料   |
| :----- | ----: |
| 洋葱   | 150克 |
| 胡萝卜 | 100克 |
| 西芹   |  80克 |
| 大蒜   |  10克 |
| 番茄膏 |  20克 |

| 香料     |
| :------- | ---: |
| 香叶     |  1片 |
| 百里香   |  1克 |
| 黑胡椒粒 |  1克 |

制作过程：  
1、牛骨敲开，牛腩切块，洋葱、胡萝卜和西芹切块，大蒜拍破  
2、锅中加入少许油，牛骨和牛腩擦干后直接煎（或烤箱210℃烤40分钟，烤盘中的焦化物用少量清水刮下，一并倒入汤锅）至深褐色，倒掉多余油脂，盛入汤锅  
3、原锅放入洋葱、胡萝卜、西芹和大蒜，炒至表面微黄，加入番茄膏炒香  
4、从主料清水中取少量倒入锅中，刮起锅底焦化物，连同蔬菜倒入汤锅  
5、加入剩余清水和香料，烧开后撇去浮沫，转小火，锅盖留缝煮4小时，其间随时撇去浮沫，水量不足时补适量开水  
6、过滤掉骨肉、蔬菜和香料，撇去浮油，冷却后分装冷藏或冷冻保存
