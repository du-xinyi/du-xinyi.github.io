---
title: "红酒汁"
---

| 主料       |
| :--------- | ----: |
| 干红葡萄酒 | 150克 |
| 牛肉褐汤   | 150克 |

| 辅料   |
| :----- | ---: |
| 红葱头 | 30克 |
| 大蒜   |  5克 |

| 调料     |
| :------- | ----: |
| 黄油     |  30克 |
| 白糖     |   3克 |
| 盐       |   1克 |
| 黑胡椒碎 | 0.5克 |

制作过程：  
1、红葱头和大蒜切末，将20克黄油切成小块后冷藏备用  
2、锅中加入剩余的10克黄油，小火加热至融化  
3、加入红葱头和大蒜，小火炒至柔软透明  
4、倒入葡萄酒，加入白糖和黑胡椒碎，中火煮至剩余约三分之一  
5、加入牛肉褐汤，继续中火熬煮至酱汁能够薄薄挂在勺背  
6、将酱汁过滤，加入盐搅拌均匀  
7、离火后分次加入冷藏黄油，搅拌至完全乳化
