---
title: "白灼汁"
---

| 料头   |
| :----- | ---: |
| 红葱头 | 10克 |
| 葱白   | 10克 |
| 大蒜   | 10克 |
| 青椒   |  8克 |
| 红椒   |  7克 |

| 调料   |
| :----- | ---: |
| 花生油 | 30克 |
| 生抽   | 40克 |
| 清水   | 35克 |
| 白糖   |  2克 |

制作过程：  
1、红葱头切片，葱白切段，大蒜拍破，青椒和红椒分别切圈  
2、锅中加入花生油，放入红葱头、葱白和大蒜，小火炒香，加入青椒圈和红椒圈翻炒几下  
3、加入生抽、清水和白糖，小火煮至汤汁微沸、白糖溶解后盛出

P.S.  
1、做白灼虾时，清水可换成等量的灼虾原汤
