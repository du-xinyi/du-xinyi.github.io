---
title: "蒸鱼酱油"
---

| 主料     |
| :------- | ----: |
| 胡萝卜   |   1根 |
| 芹菜     |   3根 |
| 鲜酱油   | 200克 |
| 蒸鱼豉油 | 100克 |
| 料酒     |  60克 |
| 冰糖     |  50克 |
| 胡椒粉   |   2克 |
| 香菜     |  适量 |
| 小茴香   |  适量 |
| 甘草     |  适量 |
| 干贝     |  适量 |
| 小虾米   |  适量 |
| 清水     |  适量 |

制作过程：  
1、胡萝卜切厚片，芹菜、香菜切段，酱油、蒸鱼豉油、料酒、冰糖、胡椒粉混合均匀，干贝和小虾米泡发  
2、锅中加入清水、胡萝卜、芹菜、香菜、小茴香和甘草，大火烧开，转小火煮20分钟，过滤出汤汁  
3、将调配好的酱油下锅，放入泡发的干贝和虾米，再倒入熬好的蔬菜汁  
4、中小火烧开后转小火煮3分钟，盛出后放凉
