---
title: "金银蒜"
---

| 主料 |
| :--- | ----: |
| 大蒜 | 200克 |

| 辅料   |
| :----- | ----: |
| 食用油 | 200克 |
| 黄油   |  10克 |

| 调料 |
| :--- | ---: |
| 盐   |  2克 |
| 白糖 |  3克 |
| 味精 |  1克 |

制作过程：  
1、大蒜去皮去根后切末，用清水冲洗后挤干水分，按六四比例分成两份  
2、锅中加入食用油，放入六成蒜末，中小火炸制，期间不断搅动  
3、蒜末炸至浅黄色时捞出，沥油后摊开放凉，炸蒜的油过滤备用  
4、剩余四成蒜末放入耐热碗中，将适量炸蒜油重新烧至约150℃（5成热），分次淋入，边淋边搅拌  
5、加入黄油、盐、白糖和味精，搅拌至黄油融化后放凉  
6、加入炸好的蒜末，拌匀，补入适量炸蒜油至刚好没过蒜末

P.S.  
1、炸蒜时先将蒜末搅散，再开火加热
