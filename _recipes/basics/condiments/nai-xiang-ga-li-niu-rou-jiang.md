---
title: "奶香咖喱牛肉酱"
---

| 主料   |
| :----- | ----: |
| 牛肉末 | 300克 |

| 辅料   |
| :----- | ----: |
| 黄洋葱 | 150克 |
| 胡萝卜 | 100克 |
| 大蒜   |  10克 |

| 调料     |
| :------- | ----: |
| 牛奶     | 250克 |
| 清水     | 150克 |
| 咖喱块   |  60克 |
| 番茄酱   |  30克 |
| 黄油     |  15克 |
| 生抽     |  10克 |
| 白糖     |   3克 |
| 黑胡椒碎 |   1克 |

制作过程：  
1、洋葱和胡萝卜切成小丁，大蒜切末  
2、锅中放入黄油，小火融化后加入洋葱和胡萝卜，炒至洋葱变软  
3、加入蒜末炒香，放入牛肉末，中火煸炒至松散并微微焦黄  
4、加入番茄酱炒香，倒入清水，加入生抽、白糖和黑胡椒碎，小火煮5分钟  
5、关火后放入咖喱块，搅拌至完全溶解  
6、加入牛奶搅拌均匀，重新开小火煮5分钟，将肉酱收至浓稠后出锅
