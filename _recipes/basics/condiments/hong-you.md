---
title: "红油"
---

| 主料       |
| :--------- | ----: |
| 明油       | 500克 |
| 子弹头辣椒 |  60克 |
| 灯笼椒     | 100克 |
| 七星椒     |  10克 |
| 熟白芝麻   |  15克 |
| 白醋       |   3克 |
| 白酒       |   5克 |

制作过程：  
1、辣椒洗净后小火炒干，捣成面，与芝麻混合均匀  
2、明油烧至7成热，关火  
3、向辣椒面中泼入适量热油，滴入少许白醋和白酒混合均匀  
4、油温降至5成热时再次泼入部分热油  
5、降至4成热后泼入全部油，加盖焖凉，密封静置24小时
