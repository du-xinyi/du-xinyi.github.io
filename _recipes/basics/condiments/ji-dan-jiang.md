---
title: "鸡蛋酱"
---

| 主料   |
| :----- | ---: |
| 鸡蛋   |  3个 |
| 香其酱 | 60克 |

| 辅料 |
| :--- | ---: |
| 青椒 | 50克 |
| 小葱 | 20克 |

| 调料 |
| :--- | ---: |
| 清水 | 80克 |

制作过程：  
1、鸡蛋搅散，青椒切丁，小葱切碎  
2、锅中加入适量油，烧热后倒入蛋液，炒成大块后盛出  
3、锅中加入少许油，放入葱花和青椒丁炒香  
4、加入香其酱，小火炒出香味  
5、加入清水搅拌均匀，小火煮3分钟  
6、放入鸡蛋，翻拌均匀后将汤汁收至浓稠
