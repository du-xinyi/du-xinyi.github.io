---
title: "枣泥核桃酪"
---

| 主料         |
| :----------- | ----: |
| 清水         |   4升 |
| 红枣（去核） | 500克 |
| 核桃仁       | 250克 |
| 糯米         | 100克 |
| 冰糖         |  50克 |

制作过程：  
1、糯米和红枣分别浸泡一晚  
2、红枣加入浸泡用水，大火烧开后转小火煮20分钟，撇去浮沫  
3、核桃仁放入预热至170℃的烤箱中烤8分钟，烤香后取出放凉  
4、核桃仁和糯米加入少量原汤打成浆，过筛备用  
5、红枣煮软后加入少量原汤打成浆，过筛备用  
6、核桃糯米浆小火边搅边煮8分钟至浓稠熟透，加入冰糖，再倒入红枣浆混合均匀  
7、小火煮开后再次过筛，根据需要加入原汤调节浓稠度

P.S.  
1、熬制时不要使用铁锅
