---
title: "拔丝地瓜"
---

| 主料 |
| :--- | ----: |
| 红薯 | 600克 |
| 白糖 | 200克 |

| 调料     |
| :------- | ----: |
| 清水     | 200克 |
| 玉米淀粉 |  30克 |
| 白醋     |   3克 |
| 盐       |   1克 |

制作过程：  
1、红薯去皮后切成滚刀块，清洗干净  
2、红薯放入清水中煮至断生，捞出过凉后充分沥干  
3、红薯加入玉米淀粉拌匀，白糖和清水混合均匀  
4、锅中加入适量油，烧至5成热，放入红薯，中小火炸约5分钟，直至内部熟透后捞出  
5、锅中倒入糖水，小火熬至白糖完全融化  
6、糖浆由大泡转为密集小泡时加入白醋和盐，继续熬至浅琥珀色，转最小火保温  
7、油烧至6成热，红薯复炸30秒至表面酥脆，捞出沥油  
8、红薯立即放入糖浆，快速翻炒至均匀裹上糖浆后出锅
