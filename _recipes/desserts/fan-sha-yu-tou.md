---
title: "翻沙芋头"
---

| 主料     |
| :------- | ----: |
| 荔浦芋头 | 700克 |
| 白糖     | 150克 |

| 调料     |
| :------- | ----: |
| 清水     | 150克 |
| 玉米淀粉 |  30克 |

制作过程：  
1、芋头洗净后去皮，切成约1厘米粗的长条  
2、芋头用清水洗净后充分沥干  
3、加入一半玉米淀粉拌匀，喷洒少量清水，再加入剩余的玉米淀粉拌匀  
4、锅中加入适量油，烧至5成热后转小火，放入芋头浸炸2分钟  
5、待表面定型后轻轻拨散，继续炸至芋头浮起并完全熟透，捞出控油  
6、白糖和清水混合后倒入锅中，中小火熬煮  
7、糖浆出现密集小泡且能够挂在锅铲上时关火  
8、放入芋头持续翻炒，直至糖浆返沙并完全冷却
