---
title: "脆皮炸鲜奶"
---

| 主料     |
| :------- | ----: |
| 牛奶     | 350克 |
| 白砂糖   |  40克 |
| 玉米淀粉 |  40克 |
| 炼乳     |  15克 |
| 鸡蛋清   |   2个 |

| 裹粉     |
| :------- | ---: |
| 玉米淀粉 | 适量 |

| 面糊     |
| :------- | ---------: |
| 低筋面粉 |      100克 |
| 玉米淀粉 |        8克 |
| 泡打粉   |        6克 |
| 蛋黄     |        2个 |
| 盐       |        1克 |
| 水       | 120～150克 |

制作过程：  
1、鸡蛋清搅散，加入牛奶、白砂糖、玉米淀粉和炼乳，搅拌至完全无颗粒  
2、倒入锅中，中小火持续搅拌，煮至浓稠并出现大气泡后继续加热30秒  
3、倒入模具，放凉后冷冻3小时，取出切成长条  
4、面糊混合均匀至无颗粒后加适量油  
5、奶冻条裹上玉米淀粉后再裹上面糊  
6、锅中加入适量油，烧至5成热，油炸30秒定型后捞出控油  
7、油温升至7成热，放入鲜奶条复炸15～20秒，炸至上色后捞出
