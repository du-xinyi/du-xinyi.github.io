---
title: "苹果派"
---

| 饼皮（8寸） |
| :---------- | ----: |
| 低筋面粉    | 250克 |
| 无盐黄油    | 125克 |
| 白砂糖      |  50克 |
| 鸡蛋        |   1个 |
| 海盐        |   1克 |

| 馅料     |
| :------- | ----: |
| 苹果     | 600克 |
| 白砂糖   |  60克 |
| 玉米淀粉 |  15克 |
| 海盐     |   1克 |
| 肉桂粉   |   3克 |
| 蜂蜜     |  10克 |
| 白兰地   |  10克 |
| 葡萄干   |  30克 |
| 蔓越莓干 |  30克 |

制作过程：  
1、鸡蛋打散后留出少量蛋液，黄油充分软化，加入白砂糖和海盐搅拌均匀，再分次加入剩余的蛋液  
2、筛入低筋面粉，切拌至无干粉后压成面团，包好冷藏30分钟  
3、苹果去皮去核后切片，加入白砂糖、海盐和肉桂粉抓拌均匀  
4、加入葡萄干和蔓越莓干，腌制30分钟后沥去多余汁水，再加入玉米淀粉、蜂蜜和白兰地拌匀  
5、取三分之二面团擀成约3毫米厚的面片，铺入模具并压紧底部和侧面，去除多余面皮  
6、放入苹果馅并压实，边缘刷上一层蛋液  
7、剩余面团擀成面片盖在表面，封紧边缘，刷上蛋液并扎出排气孔  
8、烤箱提前预热至200℃，放入中层烤20分钟，转180℃再烤30～35分钟，至表面金黄、排气孔有馅汁冒泡后取出

P.S.  
1、出炉后静置15分钟再脱模，馅料更容易定型
