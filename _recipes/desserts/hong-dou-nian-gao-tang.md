---
title: "红豆年糕汤"
---

| 主料 |
| :--- | ----: |
| 红豆 | 150克 |
| 年糕 | 200克 |

| 调料 |
| :--- | -----: |
| 冰糖 |   50克 |
| 清水 | 1200克 |

制作过程：  
1、红豆洗净，加水放入冰箱冷藏浸泡8小时，捞出沥干，年糕切片  
2、锅中加入红豆和清水，大火烧开后转小火，锅盖留缝煮90分钟，煮至红豆软烂，其间水量不足时补适量开水  
3、用料理棒将部分红豆打碎，保留部分颗粒，使汤汁略微浓稠  
4、加入冰糖，煮至完全溶解  
5、放入年糕，小火煮至软糯，其间轻轻搅动，煮好后盛出
