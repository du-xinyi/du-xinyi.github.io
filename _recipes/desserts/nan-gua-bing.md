---
title: "南瓜饼"
---

| 主料   |
| :----- | ----: |
| 南瓜   | 350克 |
| 糯米粉 | 250克 |
| 面粉   |  80克 |
| 酵母粉 |   3克 |

| 馅料     |
| :------- | ----: |
| 红糖     | 150克 |
| 熟花生碎 |  60克 |
| 熟芝麻粉 |  30克 |

| 辅料   |
| :----- | ---: |
| 黑芝麻 | 适量 |

制作过程：  
1、南瓜去皮去瓤后切片，直接铺在蒸屉上，上汽后蒸15分钟，至南瓜软熟后压成泥  
2、南瓜泥放至温热后加入酵母粉，搅拌均匀，糯米粉和面粉混合备用  
3、混合粉分次加入南瓜泥中，揉成柔软、不粘手的面团，视干湿适量调整粉量  
4、面团揉光滑，盖上保鲜膜醒面20分钟  
5、红糖、熟花生碎和熟芝麻粉混合均匀  
6、面团分成大小均匀的剂子，搓圆拍扁，包入馅料，收紧口后压成饼，表面撒上黑芝麻并轻轻压实  
7、锅中加入适量油，放入南瓜饼，中小火煎至底面金黄后翻面  
8、用锅铲轻轻按压，使饼贴紧锅底，煎至两面金黄、内部熟透后出锅
