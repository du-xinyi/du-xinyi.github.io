---
title: "琥珀桃仁"
---

| 主料   |
| :----- | ----: |
| 核桃仁 | 250克 |

| 辅料     |
| :------- | ---: |
| 熟白芝麻 | 15克 |

| 调料 |
| :--- | ----: |
| 白糖 | 100克 |
| 清水 |  50克 |

制作过程：  
1、核桃仁放入沸水中煮2分钟，捞出沥干，晾干表面水分  
2、锅中加入适量油，烧至4成热，放入核桃仁，小火炸至微黄酥脆，捞出沥油  
3、另起锅加入白糖和清水，中小火熬煮，期间轻轻晃锅  
4、糖浆颜色变为浅琥珀色时关火，放入核桃仁，快速翻拌至均匀裹上糖浆  
5、撒入白芝麻，翻拌均匀，倒在油纸上，趁热拨散  
6、放至完全冷却，装入密封容器保存
