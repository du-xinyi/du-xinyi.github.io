---
title: "浆果玫瑰冰茶"
---

| 主料     |
| :------- | ----: |
| 红茶     |   5克 |
| 草莓     |  40克 |
| 蓝莓     |  20克 |
| 树莓     |  20克 |
| 干玫瑰花 |   2克 |
| 热水     | 250克 |
| 冰块     |  适量 |

| 调料   |
| :----- | ---: |
| 蜂蜜   | 15克 |
| 柠檬汁 | 10克 |

制作过程：  
1、红茶和干玫瑰花加入热水，浸泡3分钟后过滤，放凉备用  
2、草莓、蓝莓和树莓加入蜂蜜与柠檬汁，轻轻压出汁水  
3、杯中加入冰块和浆果，倒入放凉的玫瑰红茶，搅拌均匀
