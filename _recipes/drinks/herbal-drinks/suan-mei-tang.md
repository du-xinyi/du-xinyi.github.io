---
title: "酸梅汤"
---

| 主料   |
| :----- | ----: |
| 水     |   3升 |
| 山楂   |  50克 |
| 乌梅   |  70克 |
| 甘草   |   2克 |
| 陈皮   |   8克 |
| 洛神花 |   6克 |
| 桑葚   |  10克 |
| 枸杞   |   5克 |
| 薄荷   |   1克 |
| 干桂花 |   1克 |
| 冰糖   | 230克 |

制作过程：  
1、除水、冰糖、干桂花和薄荷外的主料洗净，与水一同放入锅中浸泡30分钟后大火烧开  
2、转小火煮40分钟，加入冰糖搅拌至融化  
3、加入薄荷浸泡5分钟后过滤，盆中干桂花打底加入酸梅汤冲开  
4、放凉后放入冰箱冷藏3小时

P.S.  
1、熬制时切忌使用铁锅  
2、可以加1～2克盐提味解腻
