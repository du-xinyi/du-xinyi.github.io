---
title: "小酥肉"
---

| 主料   |
| :----- | ----: |
| 里脊肉 | 250克 |

| 腌料 |
| :--- | ---: |
| 小葱 | 10克 |
| 生姜 | 10克 |
| 料酒 | 15克 |
| 盐   |  3克 |
| 花椒 |  2克 |

| 面糊     |
| :------- | ----: |
| 红薯淀粉 | 110克 |
| 面粉     |  10克 |
| 鸡蛋     |   2个 |
| 花椒粉   |   4克 |

制作过程：  
1、里脊肉切条，小葱切段，生姜切片  
2、肉条加入腌料抓拌均匀，腌制15分钟后拣去葱姜和花椒  
3、面糊混合均匀，调至能均匀挂住肉条、多余面糊缓慢滴落的状态，放入肉条，使表面均匀裹糊  
4、锅中加入适量油，烧至5成热，逐条放入肉条，炸至定型并熟透后捞出  
5、油温升至7成热，放入酥肉复炸至表面金黄酥脆
