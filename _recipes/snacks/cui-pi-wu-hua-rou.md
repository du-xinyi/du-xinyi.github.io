---
title: "脆皮五花肉"
---

| 主料   |
| :----- | ----: |
| 五花肉 | 500克 |

| 腌料   |
| :----- | ---: |
| 盐     |  7克 |
| 孜然粉 |  5克 |
| 花椒粉 |  4克 |
| 辣椒粉 | 20克 |
| 十三香 |  4克 |

| 脆皮水 |
| :----- | ---: |
| 清水   | 50克 |
| 盐     |  6克 |
| 小苏打 |  6克 |

| 辅料 |
| :--- | ----: |
| 黄酒 | 100克 |
| 白醋 |   5克 |

制作过程：  
1、五花肉切成两指宽的长条，加入黄酒浸泡10分钟后擦干水分  
2、肉皮涂抹少量盐，腌制5分钟后擦干  
3、肉面加入腌料抓拌均匀，冷藏腌制2小时以上  
4、清水、盐和小苏打混合成脆皮水，刮去肉皮上的腌料，在肉皮上均匀涂抹一层  
5、肉皮表面干燥后再次涂抹脆皮水，继续敞口冷藏风干4小时以上，至肉皮完全干硬  
6、五花肉用锡纸包住肉面并露出肉皮，放入160℃烤箱烤40分钟  
7、打开锡纸顶部露出肉皮（锡纸仍包住肉面），在肉皮表面涂抹白醋，放在烤网上，以230℃继续烤15～25分钟至肉皮均匀起泡
