---
title: "薯条"
---

| 主料 |
| :--- | ----: |
| 土豆 | 500克 |

| 调料     |
| :------- | ---: |
| 玉米淀粉 | 15克 |
| 盐       |  3克 |

制作过程：  
1、土豆去皮后切成约1厘米粗的条，冲洗掉表面淀粉后浸泡20分钟  
2、锅中烧水，水开后放入土豆条煮2分钟，捞出后充分沥干并晾凉  
3、加入玉米淀粉拌匀，使土豆条表面均匀裹粉  
4、锅中加入适量油，烧至150℃，放入土豆条炸5分钟，捞出放凉  
5、油温升至190℃，复炸1～2分钟至表面金黄酥脆  
6、捞出沥油，趁热撒盐后拌匀
