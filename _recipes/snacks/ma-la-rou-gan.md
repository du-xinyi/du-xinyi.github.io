---
title: "麻辣肉干"
---

| 主料       |
| :--------- | ----: |
| 牛（羊）肉 | 750克 |

| 辅料     |
| :------- | ----: |
| 油酥花生 | 100克 |

| 调料 |
| :--- | ---: |
| 冰糖 | 50克 |
| 生抽 | 15克 |

| 干料   |
| :----- | ---: |
| 花椒面 | 适量 |
| 辣椒面 | 适量 |
| 孜然面 | 适量 |
| 五香粉 | 适量 |

| 卤料   |
| :----- | -----: |
| 水     | 1250克 |
| 八角   |    2个 |
| 香叶   |    3片 |
| 花椒   |    3克 |
| 干辣椒 |    5克 |
| 姜     |   25克 |
| 紫洋葱 |  100克 |
| 老抽   |   10克 |
| 盐     |   15克 |
| 料酒   |  100克 |

| 料头   |
| :----- | ---: |
| 八角   |  2个 |
| 香叶   |  3片 |
| 花椒   |  3克 |
| 姜     |  2片 |
| 紫洋葱 |  5克 |

制作过程：  
1、花生稍微切碎，牛（羊）肉切条后焯水，水开后煮5分钟，捞出洗净  
2、肉条放入卤料中，烧开后煮40分钟，关火，浸泡10分钟捞出，再拌入少许生抽  
3、锅中加入适量油，烧至7成热，将肉条炸3分钟后捞出控油  
4、锅中加入适量油，烧热后下入料头，炒至略干时倒入少许清水，再加入少许盐和生抽，熬香后捞出料渣  
5、加入冰糖，熬化后加入肉条，翻炒至水分将干时加入花生碎  
6、加入适量花椒面、辣椒面、孜然面，少许五香粉，翻炒均匀
