---
title: "金沙玉米"
---

| 主料     |
| :------- | ----: |
| 甜玉米粒 | 300克 |
| 咸蛋黄   |   2个 |

| 辅料 |
| :--- | ---: |
| 青椒 | 20克 |
| 红椒 | 20克 |

| 调料     |
| :------- | ---: |
| 土豆淀粉 | 30克 |
| 红薯淀粉 | 20克 |
| 盐       |  1克 |

制作过程：  
1、青椒和红椒切粒，咸蛋黄压成泥  
2、玉米粒焯水后捞出，充分沥干水分  
3、先加入一半土豆淀粉抓匀，再加入红薯淀粉抓匀，最后加入剩余的土豆淀粉，使玉米粒均匀裹粉  
4、锅中加入油，烧至6成热，放入玉米粒，中火炸至表面酥脆后捞出控油  
5、锅中留少许底油，放入咸蛋黄，小火炒至起沙冒泡  
6、加入玉米粒、青椒、红椒和盐，快速翻炒均匀后出锅
