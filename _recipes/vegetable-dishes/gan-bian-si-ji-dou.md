---
title: "干煸四季豆"
---

| 主料   |
| :----- | ----: |
| 四季豆 | 400克 |

| 辅料   |
| :----- | ----: |
| 五花肉 | 150克 |
| 芽菜   |   5克 |
| 大蒜   |  10克 |
| 生姜   |   5克 |

| 料头     |
| :------- | ---: |
| 青花椒   |  3克 |
| 干辣椒段 | 10克 |

| 调料 |
| :--- | ---: |
| 盐   |  3克 |
| 白糖 |  2克 |
| 香醋 |  5克 |

制作过程：  
1、四季豆掐去头尾后折成长段，五花肉去皮后剁成肉末，大蒜和生姜切末  
2、锅中加入适量油，放入四季豆，中小火煸至表面发皱并完全熟透后盛出  
3、锅中加入适量油，放入肉末煸至酥香  
4、加入青花椒、干辣椒段、姜末、蒜末和芽菜，炒出香味  
5、放回四季豆，加入盐和白糖翻炒均匀  
6、沿锅边淋入香醋，翻炒均匀后出锅
