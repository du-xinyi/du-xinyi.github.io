---
title: "炝炒莲花白"
---

| 主料   |
| :----- | ----: |
| 莲花白 | 500克 |

| 料头   |
| :----- | ---: |
| 花椒   |  2克 |
| 大蒜   | 10克 |
| 干辣椒 | 10克 |

| 调料 |
| :--- | ---: |
| 生抽 | 10克 |
| 盐   |  3克 |
| 香醋 |  5克 |

制作过程：  
1、莲花白拍散后切块，大蒜切片，干辣椒切段  
2、锅中加入适量油，烧热后放入花椒、蒜片和干辣椒炒香  
3、放入莲花白，中大火炒至断生  
4、加入生抽和盐翻炒均匀  
5、沿锅边淋入香醋，翻炒均匀后出锅
