---
title: "洋葱炒鸡蛋"
---

| 主料   |
| :----- | ----: |
| 紫洋葱 | 300克 |
| 鸡蛋   |   3个 |

| 辅料 |
| :--- | ---: |
| 青椒 | 半个 |
| 红椒 | 半个 |

| 调料 |
| :--- | ----: |
| 盐   |   2克 |
| 白糖 |   2克 |
| 白醋 | 0.5克 |
| 蚝油 |   4克 |

制作过程：  
1、洋葱去除头尾后对半切开，切成小块，青椒、红椒切成小块，鸡蛋稍微搅散  
2、锅中加入适量油，烧至5成热，加入洋葱和青红椒，中火炒至断生后盛出  
3、锅中重新加入适量油，烧至5成热，离火，倒入蛋液煎至定型  
4、重新开中火，将鸡蛋炒香  
5、加入盐、白糖、白醋和蚝油，翻炒均匀  
6、加入适量水淀粉勾薄芡  
7、加入洋葱和青红椒，大火翻炒均匀后出锅
