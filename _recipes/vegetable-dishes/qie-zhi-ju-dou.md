---
title: "茄汁焗豆"
---

| 主料       |
| :--------- | ----: |
| 鹰嘴豆罐头 | 380克 |
| 番茄       | 200克 |

| 辅料   |
| :----- | ---: |
| 培根   | 50克 |
| 黄洋葱 | 50克 |
| 大蒜   |  5克 |

| 调料     |
| :------- | ----: |
| 番茄酱   |  40克 |
| 辣椒酱   |  10克 |
| 清水     |  60克 |
| 白糖     |   5克 |
| 盐       |   2克 |
| 白醋     |   3克 |
| 辣椒粉   |   1克 |
| 黑胡椒碎 | 0.5克 |

制作过程：  
1、鹰嘴豆倒出后冲洗干净并沥干水分，番茄去皮后切碎，培根切成小块，洋葱和大蒜切末  
2、锅中放入培根，小火煸出油脂并炒至微黄  
3、加入洋葱末炒软，再加入蒜末炒香  
4、加入番茄酱和辣椒酱，小火炒出香味后放入番茄，炒至软烂  
5、加入清水、白糖、盐、辣椒粉和黑胡椒碎，搅拌均匀后放入鹰嘴豆  
6、小火煮15分钟，将汤汁收至浓稠  
7、加入白醋搅拌均匀后出锅
