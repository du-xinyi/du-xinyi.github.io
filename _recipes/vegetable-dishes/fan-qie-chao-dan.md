---
title: "番茄炒蛋"
---

| 主料 |
| :--- | ----: |
| 番茄 | 400克 |
| 鸡蛋 |   4个 |

| 辅料 |
| :--- | ---: |
| 小葱 | 10克 |

| 甜口调料 |
| :------- | ---: |
| 白糖     | 15克 |
| 盐       |  4克 |

| 咸口调料 |
| :------- | ---: |
| 盐       |  5克 |
| 白糖     |  3克 |

| 辣口辅料 |
| :------- | ---: |
| 青椒     | 50克 |

| 辣口调料 |
| :------- | ---: |
| 盐       |  4克 |
| 白糖     |  5克 |

制作过程：  
1、番茄去蒂后切块，鸡蛋中加入1克盐（取1克所选口味的盐）搅散，小葱切碎，制作辣口时将青椒切块  
2、锅中加入适量油，烧热后倒入蛋液，炒成大块后盛出  
3、锅中加入少许油，放入一半葱花炒香，制作辣口时加入青椒，炒至断生  
4、放入番茄，加入所选口味对应的剩余盐和白糖，炒至番茄软烂出汁  
5、放回鸡蛋，翻炒至蛋块均匀裹上汤汁  
6、撒上剩余的葱花后出锅
