---
title: "糖醋莲花白"
---

| 主料   |
| :----- | ----: |
| 莲花白 | 500克 |

| 料头     |
| :------- | ---: |
| 干辣椒段 | 10克 |
| 花椒     |  2克 |
| 生姜     |  5克 |
| 小葱     | 10克 |
| 大蒜     | 10克 |

| 调料 |
| :--- | ---: |
| 白糖 | 25克 |
| 香醋 | 20克 |
| 盐   |  4克 |

制作过程：  
1、莲花白去芯，拍散后切成菱形块，生姜和大蒜切末，小葱切段  
2、锅中加入适量油，烧热后放入莲花白和2克盐，大火炒至断生并略微变干，盛出  
3、锅中重新加入适量油，放入干辣椒段、花椒、姜末、葱段和蒜末炒香  
4、放回莲花白，加入白糖和剩余的盐，翻炒均匀  
5、加入适量水淀粉勾薄芡，沿锅边淋入香醋，翻炒均匀后出锅
