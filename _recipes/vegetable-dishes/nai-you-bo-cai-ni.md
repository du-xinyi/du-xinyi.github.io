---
title: "奶油菠菜泥"
---

| 主料   |
| :----- | ----: |
| 菠菜   | 300克 |
| 淡奶油 |  80克 |
| 牛奶   |  50克 |

| 辅料   |
| :----- | ---: |
| 黄油   | 15克 |
| 黄洋葱 | 30克 |
| 大蒜   |  5克 |
| 面粉   |  5克 |

| 调料     |
| :------- | ----: |
| 盐       |   2克 |
| 白胡椒粉 | 0.3克 |
| 肉豆蔻粉 | 0.1克 |

制作过程：  
1、菠菜清洗干净，放入沸水中焯水30秒，捞出过凉后挤干水分  
2、菠菜切碎，加入牛奶搅打成菠菜泥  
3、洋葱和大蒜切末  
4、锅中加入黄油，小火融化后放入洋葱末和蒜末，炒至洋葱变软  
5、加入面粉，小火翻炒1分钟  
6、倒入菠菜泥和淡奶油，搅拌均匀后小火煮至浓稠  
7、加入盐、白胡椒粉和肉豆蔻粉，搅拌均匀后出锅

P.S.  
1、菠菜焯水后应充分挤干，避免成品水分过多  
2、搅打时间不宜过长，保留少量菠菜颗粒口感更丰富
