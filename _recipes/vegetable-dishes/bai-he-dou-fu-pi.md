---
title: "柏合豆腐皮"
---

| 主料   |
| :----- | ----: |
| 豆腐皮 | 200克 |

| 辅料   |
| :----- | ---: |
| 猪肉末 | 50克 |
| 蒜苗   | 30克 |
| 大蒜   | 10克 |
| 生姜   |  5克 |
| 豆豉   | 10克 |

| 调料         |
| :----------- | ----: |
| 郫县豆瓣酱   |  25克 |
| 辣椒粉       |  10克 |
| 花椒粉       |   2克 |
| 生抽         |  10克 |
| 味精         |   2克 |
| 鸡架猪骨清汤 | 300克 |

制作过程：  
1、豆腐皮卷起后切成尽可能细的丝，大蒜和生姜切末，蒜苗切花  
2、锅中烧水，放入豆腐皮煮3分钟，捞出后用清水冲凉并沥干水分  
3、锅中加入油，烧热后放入猪肉末，煸炒至酥香  
4、加入姜末、蒜末、豆瓣酱和豆豉，小火炒香并炒出红油  
5、加入辣椒粉炒香，倒入鸡架猪骨清汤，加入生抽和味精烧开  
6、放入豆腐皮，小火煮3分钟，使其充分吸收汤汁  
7、将水淀粉分三次沿锅边淋入，每次轻轻推动豆腐皮，待芡汁收紧后再加入下一次  
8、待汤汁浓稠并完全附着在豆腐皮上，加入一半蒜苗和花椒粉，轻轻推匀  
9、盛入碗中，撒上剩余的蒜苗后食用
