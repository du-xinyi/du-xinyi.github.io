---
title: "鱼香茄子"
---

| 主料 |
| :--- | ----: |
| 茄子 | 500克 |

| 辅料   |
| :----- | ----: |
| 二刀肉 | 150克 |
| 小葱   |  10克 |

| 料头 |
| :--- | ---: |
| 大蒜 | 20克 |
| 泡姜 | 15克 |
| 泡椒 | 30克 |

| 料汁 |
| :--- | ---: |
| 盐   |  1克 |
| 白糖 | 20克 |
| 生抽 | 10克 |
| 香醋 |  6克 |
| 清水 | 30克 |

| 调料     |
| :------- | ---: |
| 白醋     |  5克 |
| 玉米淀粉 | 10克 |

制作过程：  
1、茄子洗净后切条，加入白醋和玉米淀粉拌匀，中火蒸15分钟  
2、二刀肉剁成肉末，大蒜、泡姜和泡椒切末，小葱切花，料汁混合均匀  
3、锅中加入适量油，放入肉末，中小火炒香  
4、加入蒜末、泡姜和泡椒，小火炒出香味  
5、倒入料汁，加入水淀粉后小火将汤汁收浓  
6、放入茄子，翻炒至均匀裹上汤汁  
7、加入适量明油翻炒均匀，撒上葱花后出锅
