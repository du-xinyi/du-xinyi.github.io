---
title: "包菜炒粉丝"
---

| 主料 |
| :--- | ----: |
| 包菜 | 300克 |
| 粉丝 |  80克 |
| 鸡蛋 |   2个 |

| 辅料   |
| :----- | ---: |
| 大蒜   | 10克 |
| 小米辣 | 10克 |
| 小葱   | 10克 |

| 调料 |
| :--- | ---: |
| 生抽 | 10克 |
| 老抽 |  2克 |
| 白糖 |  3克 |
| 盐   |  3克 |
| 香醋 |  5克 |
| 清水 | 10克 |

制作过程：  
1、包菜去芯后切丝，粉丝泡软后剪短，加入老抽和适量油拌匀  
2、大蒜切末，小米辣切段，小葱切花，鸡蛋加入清水搅散  
3、锅中加入适量油，烧热后倒入蛋液，炒散后盛出  
4、锅中加入适量油，放入蒜末和小米辣爆香，再放入包菜，大火炒至断生  
5、加入生抽、白糖和盐，放入鸡蛋和粉丝，翻炒至粉丝吸收汤汁  
6、沿锅边淋入香醋，撒上葱花后出锅
