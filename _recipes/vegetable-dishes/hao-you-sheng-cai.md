---
title: "蚝油生菜"
---

| 主料 |
| :--- | ----: |
| 生菜 | 500克 |

| 辅料 |
| :--- | ---: |
| 大蒜 | 15克 |

| 料汁 |
| :--- | ---: |
| 蚝油 | 15克 |
| 生抽 | 10克 |
| 老抽 |  2克 |
| 白糖 |  3克 |
| 盐   |  2克 |
| 清水 | 80克 |

制作过程：  
1、生菜清洗干净，大蒜切末，料汁混合均匀  
2、锅中烧水，加入少许油，放入生菜焯至断生，捞出沥干后装盘  
3、锅中倒入料汁，小火烧开后加入水淀粉收至略微浓稠  
4、加入蒜末煮至断生，再加入适量明油搅匀，淋在生菜上
