---
title: "豆豉鲮鱼油麦菜"
---

| 主料   |
| :----- | ----: |
| 油麦菜 | 400克 |

| 辅料         |
| :----------- | ----: |
| 豆豉鲮鱼罐头 | 120克 |
| 大蒜         |  10克 |

| 调料   |
| :----- | ---: |
| 白糖   |  2克 |
| 罐头油 | 15克 |

制作过程：  
1、油麦菜洗净后沥干水分，切成长段并将菜梗和菜叶分开，大蒜切末，豆豉鲮鱼撕成小块  
2、锅烧热后加入罐头油，放入蒜末和罐头中的豆豉，小火炒香  
3、加入豆豉鲮鱼和白糖，翻炒均匀  
4、转大火放入油麦菜梗，翻炒30秒  
5、加入油麦菜叶，继续大火翻炒至断生后出锅
