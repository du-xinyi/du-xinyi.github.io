---
title: "清炒山药木耳"
---

| 主料   |
| :----- | ----: |
| 山药   | 300克 |
| 干木耳 |  10克 |

| 辅料   |
| :----- | ---: |
| 青椒   | 50克 |
| 胡萝卜 | 50克 |
| 大蒜   | 10克 |

| 调料 |
| :--- | ---: |
| 盐   |  3克 |
| 白糖 |  1克 |
| 香油 |  3克 |

制作过程：  
1、木耳泡发后洗净，撕成小朵，山药去皮切薄片，青椒和胡萝卜切片，大蒜切片  
2、锅中烧水，放入木耳煮2分钟，加入山药和胡萝卜继续焯水1分钟，捞出沥干  
3、锅中加入适量油，放入蒜片炒香  
4、加入山药、木耳、胡萝卜和青椒，大火翻炒至青椒断生  
5、加入盐和白糖，淋入少许清水，翻炒均匀  
6、淋入香油，翻炒均匀后出锅
