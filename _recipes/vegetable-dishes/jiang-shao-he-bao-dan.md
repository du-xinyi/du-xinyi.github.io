---
title: "酱烧荷包蛋"
---

| 主料 |
| :--- | ---: |
| 鸡蛋 |  4个 |

| 辅料 |
| :--- | ---: |
| 小葱 | 10克 |

| 料汁 |
| :--- | ---: |
| 清水 | 80克 |
| 生抽 | 15克 |
| 老抽 |  3克 |
| 白糖 |  8克 |

制作过程：  
1、小葱切段，料汁混合均匀  
2、锅中加入适量油，中火烧热后依次打入鸡蛋  
3、鸡蛋煎至两面金黄、内部六七成熟后盛出  
4、锅中留少许底油，加入葱段炒香  
5、倒入料汁烧开，放入荷包蛋，中小火烧2分钟  
6、将汤汁收至略微浓稠后出锅

P.S.  
1、荷包蛋不宜提前煎至全熟，回锅烧制后口感更嫩
