---
title: "芝士牛肉饼三明治"
---

| 主料   |
| :----- | ----: |
| 吐司   |   2片 |
| 牛肉馅 | 100克 |
| 鸡蛋   |   1个 |
| 芝士片 |   1片 |
| 黄油   |  10克 |

| 辅料   |
| :----- | ---: |
| 黄洋葱 | 15克 |
| 番茄   |  2片 |
| 生菜   |  2片 |

| 调料     |
| :------- | ----: |
| 盐       |   1克 |
| 黑胡椒粉 | 0.3克 |

制作过程：  
1、洋葱切末，番茄切片，生菜洗净后沥干水分  
2、锅中加入少许黄油，小火将洋葱末炒软，盛出放凉  
3、牛肉馅加入洋葱末、盐和黑胡椒粉，搅拌至能够黏合  
4、将肉馅摔打排出空气，整理成略大于吐司、厚约1厘米的肉饼，中间轻轻压出凹槽  
5、平底锅烧热，放入肉饼，中火煎至底面上色后翻面，转中小火煎至完全熟透  
6、锅中打入鸡蛋，煎至蛋白凝固、蛋黄达到需要的熟度后盛出  
7、吐司单面薄涂黄油，涂黄油面朝外，依次夹入芝士、肉饼和煎蛋  
8、将吐司放入锅中，小火煎至底面金黄后翻面，继续煎至另一面金黄、芝士融化  
9、从中间打开，放入番茄片和生菜，合拢后对半切开

P.S.  
1、建议使用肥瘦约二八比例的牛肉馅  
2、煎制过程中不要反复按压肉饼，以免肉汁流失
