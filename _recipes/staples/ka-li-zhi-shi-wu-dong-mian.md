---
title: "咖喱芝士乌冬面"
---

| 主料   |
| :----- | ----: |
| 乌冬面 | 200克 |

| 辅料         |
| :----------- | ----: |
| 肥牛片       | 100克 |
| 黄洋葱       |  60克 |
| 马苏里拉芝士 |  50克 |
| 小葱         |  10克 |

| 汤底   |
| :----- | ----: |
| 清水   | 300克 |
| 牛奶   | 100克 |
| 咖喱块 |  25克 |
| 生抽   |  10克 |
| 味淋   |  10克 |

制作过程：  
1、洋葱切丝，小葱切碎，咖喱块切碎  
2、锅中加入少许油，烧热后放入洋葱，中火炒至变软  
3、加入肥牛片，翻炒至变色  
4、加入清水、生抽和味淋，烧开后撇去浮沫  
5、转小火加入咖喱块，搅拌至完全融化  
6、加入牛奶和乌冬面，小火煮3分钟，使面条散开并吸收汤汁  
7、将芝士均匀铺在表面，加盖小火煮至芝士融化  
8、撒上葱花后出锅
