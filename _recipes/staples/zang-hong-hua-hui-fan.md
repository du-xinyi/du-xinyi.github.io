---
title: "藏红花烩饭"
---

| 主料         |
| :----------- | ----: |
| 意大利烩饭米 | 200克 |

| 辅料       |
| :--------- | ---: |
| 黄洋葱     | 60克 |
| 帕尔马干酪 | 30克 |

| 调料       |
| :--------- | ----: |
| 鸡肉清汤   | 800克 |
| 干白葡萄酒 |  50克 |
| 黄油       |  30克 |
| 藏红花     | 0.1克 |
| 盐         |  适量 |

制作过程：  
1、洋葱切末，帕尔马干酪擦碎  
2、鸡肉清汤加热至微沸，取50克浸泡藏红花，剩余清汤保持温热  
3、锅中放入15克黄油，小火融化后加入洋葱，炒至透明  
4、加入烩饭米，中小火翻炒2分钟，倒入干白葡萄酒，煮至酒液基本收干  
5、加入一勺温热的鸡肉清汤，中小火煮，其间轻轻搅动，待汤汁基本被吸收后继续分次加汤  
6、煮至15分钟时，倒入藏红花及浸泡的汤汁，继续按状态补汤，煮至米粒熟透、略有嚼劲，米饭湿润且能缓缓流动  
7、关火，加入剩余黄油和帕尔马干酪，搅拌至完全融化，加盐调味后装盘

P.S.  
1、装盘前若米饭偏稠，补少量温热的鸡肉清汤，拌至能缓缓流动
