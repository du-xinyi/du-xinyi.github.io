---
title: "番茄鸡蛋面"
---

| 主料 |
| :--- | ----: |
| 面条 | 200克 |
| 番茄 | 300克 |
| 鸡蛋 |   2个 |

| 辅料 |
| :--- | ---: |
| 小葱 | 10克 |

| 调料     |
| :------- | ----: |
| 盐       |   4克 |
| 白糖     |   5克 |
| 白胡椒粉 | 0.5克 |
| 香油     |   5克 |

制作过程：  
1、番茄去蒂后切块，鸡蛋搅散，小葱切碎  
2、锅中加入适量油，烧热后倒入蛋液，炒成大块后盛出  
3、锅中加入少许油，放入一半葱花炒香，再加入番茄、白糖和2克盐，炒至软烂出汁  
4、加入适量清水烧开，放入面条煮熟  
5、加入鸡蛋、剩余的盐和白胡椒粉，搅拌均匀  
6、淋入香油，撒上剩余的葱花后出锅
