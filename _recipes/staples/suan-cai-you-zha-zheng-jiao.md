---
title: "酸菜油渣蒸饺"
---

| 主料   |
| :----- | ----: |
| 酸白菜 | 400克 |
| 梅花肉 | 250克 |
| 猪油渣 | 100克 |
| 饺子皮 |  36张 |

| 辅料 |
| :--- | ---: |
| 猪油 | 40克 |
| 小葱 | 30克 |
| 生姜 | 10克 |

| 香料 |
| :--- | ---: |
| 八角 |  1个 |
| 香叶 |  1片 |
| 花椒 |  2克 |

| 调料     |
| :------- | ---: |
| 十三香   |  2克 |
| 生抽     | 15克 |
| 蚝油     | 10克 |
| 盐       |  1克 |
| 味精     |  2克 |
| 白胡椒粉 |  1克 |

制作过程：  
1、酸菜用清水浸泡10分钟，捞出挤去大部分水分，切碎后再轻轻攥干  
2、梅花肉剁成肉馅，猪油渣切碎，小葱切花，生姜切片  
3、锅中加入猪油，放入生姜、八角、香叶和花椒，小火炸出香味后捞出料渣  
4、转中火放入肉馅，煸炒至刚熟  
5、加入十三香翻炒均匀，盛出一半肉馅，将剩余肉馅继续煸炒至焦香，全部盛出放凉  
6、将酸菜、两种熟度的肉馅和猪油渣混合均匀  
7、加入生抽、蚝油、盐、味精、白胡椒粉和葱花，搅拌均匀制成馅料  
8、将馅料包入饺子皮，捏成蒸饺  
9、蒸锅上汽后放入蒸饺，大火蒸12分钟后出锅
