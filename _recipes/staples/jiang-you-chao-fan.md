---
title: "酱油炒饭"
---

| 主料   |
| :----- | ----: |
| 熟米饭 | 400克 |
| 鸡蛋   |   2个 |

| 辅料 |
| :--- | ---: |
| 小葱 | 15克 |

| 调料     |
| :------- | ----: |
| 生抽     |  15克 |
| 老抽     |   3克 |
| 白糖     |   2克 |
| 白胡椒粉 | 0.5克 |

制作过程：  
1、米饭提前拨散，鸡蛋打散，小葱切葱花，葱白和葱绿分开  
2、锅烧热后加入适量猪油，倒入蛋液，炒成小块后盛出  
3、锅中加入适量猪油，放入葱白炒香  
4、加入米饭，中大火翻炒至米粒松散、表面略干  
5、加入生抽、老抽、白糖和白胡椒粉，翻炒至上色均匀、酱香散出  
6、放回鸡蛋，加入葱绿，翻炒均匀后出锅
