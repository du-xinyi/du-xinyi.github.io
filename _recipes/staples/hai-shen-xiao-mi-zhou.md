---
title: "海参小米粥"
---

| 主料     |
| :------- | ----: |
| 水发海参 |   2只 |
| 小米     | 100克 |

| 辅料 |
| :--- | ---: |
| 生姜 | 10克 |
| 小葱 | 10克 |

| 调料         |
| :----------- | ----: |
| 清水         | 800克 |
| 鸡架猪骨清汤 | 300克 |
| 盐           |   4克 |
| 白胡椒粉     | 0.5克 |
| 香油         |   2克 |

制作过程：  
1、小米淘洗干净，海参清理干净后切成厚段，生姜切丝，小葱的葱白切段、葱叶切花  
2、锅中加入鸡架猪骨清汤、一半姜丝、葱白和2克盐，烧开后放入海参，小火煨8分钟  
3、关火后加盖浸泡10分钟，捞出海参，去除葱白，煨海参的鸡架猪骨清汤保留  
4、另起锅加入清水烧开，放入小米搅散，再次烧开后转小火，锅盖留缝煮30分钟  
5、倒入煨海参的鸡架猪骨清汤，加入剩余姜丝，搅拌均匀后继续小火煮10分钟  
6、放入海参，加入剩余的盐和白胡椒粉，小火煮3分钟  
7、淋入香油，撒上葱花后出锅
