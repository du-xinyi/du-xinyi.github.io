---
title: "木须肉"
---

| 主料   |
| :----- | ----: |
| 五花肉 | 200克 |
| 干木耳 |  10克 |
| 干黄花 |  15克 |
| 鸡蛋   |   2个 |

| 料汁   |
| :----- | ---: |
| 生抽   | 15克 |
| 料酒   | 10克 |
| 葱姜水 | 10克 |
| 盐     |  2克 |

| 辅料 |
| :--- | ---: |
| 香油 |  5克 |

制作过程：  
1、干木耳和干黄花分别用清水泡发，洗净后挤干水分；五花肉、木耳切丝，黄花去芯，鸡蛋打散  
2、鸡蛋炒熟后盛出，锅中加入适量油，烧热后将肉丝炒至断生，再加入料汁  
3、炒至水分蒸发后加入木耳和黄花，翻炒均匀后加入鸡蛋  
4、翻炒均匀后淋入香油
