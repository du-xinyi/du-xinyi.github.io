---
title: "煎牛排"
---

| 主料 |
| :--- | ----: |
| 牛排 | 300克 |

| 辅料   |
| :----- | ---: |
| 大蒜   | 10克 |
| 迷迭香 |  2克 |

| 调料     |
| :------- | ---: |
| 盐       |  3克 |
| 黑胡椒碎 |  1克 |
| 黄油     | 20克 |

制作过程：  
1、牛排提前取出回温30分钟，用厨房纸吸干表面水分，大蒜拍裂  
2、牛排两面均匀撒上盐和黑胡椒碎，轻轻按压使其附着  
3、平底锅充分烧热，加入油，放入牛排，大火煎90秒  
4、将牛排翻面继续煎90秒，再夹起牛排，将脂肪边缘煎至焦香  
5、转中小火，加入黄油、大蒜和迷迭香，待黄油融化起泡后不断淋在牛排表面，中心温度比表中对应的目标温度低3～5℃时离火  
6、牛排出锅后静置5分钟，逆着纹理切片

P.S.  

| 熟度   | 静置后中心温度 |
| :----- | -------------: |
| 一分熟 |        49～52℃ |
| 三分熟 |        53～57℃ |
| 五分熟 |        58～62℃ |
| 七分熟 |        63～68℃ |
| 全熟   |        69℃以上 |
