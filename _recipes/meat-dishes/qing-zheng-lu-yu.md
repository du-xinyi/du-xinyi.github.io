---
title: "清蒸鲈鱼"
---

| 主料 |
| :--- | -------------: |
| 鲈鱼 | 1条（约500克） |

| 辅料 |
| :--- | ---: |
| 小葱 | 20克 |
| 生姜 | 20克 |
| 大葱 | 20克 |
| 红椒 | 10克 |

| 调料     |
| :------- | ---: |
| 盐       |  2克 |
| 猪油     |  5克 |
| 蒸鱼酱油 | 25克 |

制作过程：  
1、鲈鱼去除鱼鳞、鱼鳃、内脏和腹腔黑膜，用盐轻轻搓洗后冲洗干净  
2、小葱切段，部分生姜切片，鱼身两侧各切两道斜刀，盘底垫上姜片和小葱段，将鱼架起放入盘中  
3、鱼身薄薄涂抹猪油，蒸锅上汽后放入，大火蒸8分钟，关火焖2分钟  
4、大葱、红椒和剩余的生姜切细丝，鱼蒸好后倒掉盘中汁水，去除垫底的葱姜  
5、将葱丝、姜丝和红椒丝铺在鱼身上  
6、适量油烧至7成热，均匀淋在辅料上，再沿盘边淋入蒸鱼酱油

P.S.  
1、鱼重每增加100克，蒸制时间可增加约1分钟
