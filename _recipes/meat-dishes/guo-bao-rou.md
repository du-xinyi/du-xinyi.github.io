---
title: "锅包肉"
---

| 主料   |
| :----- | ----: |
| 里脊肉 | 200克 |

| 腌料     |
| :------- | ----: |
| 盐       |   2克 |
| 白胡椒粉 | 0.5克 |
| 料酒     |  10克 |

| 挂糊     |
| :------- | ----: |
| 土豆淀粉 | 100克 |

| 辅料   |
| :----- | ---: |
| 胡萝卜 | 10克 |
| 香菜   | 10克 |
| 大葱   |  5克 |
| 生姜   |  5克 |
| 大蒜   |  5克 |

| 料汁 |
| :--- | ---: |
| 白糖 | 30克 |
| 白醋 | 20克 |
| 盐   |  1克 |
| 清水 | 30克 |

制作过程：  
1、里脊肉切成约3毫米厚的片，加入腌料抓拌均匀，腌制10分钟  
2、土豆淀粉加入清水泡开，静置30分钟后倒掉上层清水，留下湿淀粉，加入油混合均匀  
3、胡萝卜、香菜、大葱和生姜切细丝，大蒜切片  
4、肉片加入挂糊抓拌均匀  
5、锅中加入适量油，烧至5成热，放入肉片，中火炸至定型并熟透后捞出  
6、油温升至7成热，放入肉片复炸30秒，捞出控油  
7、锅中倒入料汁，烧开后熬至略微黏稠，加入辅料翻炒均匀  
8、放入炸好的肉片，快速翻炒至均匀裹汁后出锅
