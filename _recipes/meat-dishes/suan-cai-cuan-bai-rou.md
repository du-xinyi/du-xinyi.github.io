---
title: "酸菜汆白肉"
---

| 主料   |
| :----- | ----: |
| 五花肉 | 200克 |
| 酸白菜 | 400克 |
| 粉丝   | 100克 |

| 料头 |
| :--- | ---: |
| 生姜 | 10克 |
| 小葱 | 10克 |
| 大蒜 |  5克 |
| 花椒 |  2克 |
| 八角 |  1个 |

| 调料     |
| :------- | ----: |
| 盐       |   3克 |
| 白胡椒粉 | 0.5克 |

| 辅料 |
| :--- | ---: |
| 香菜 | 10克 |

制作过程：  
1、粉丝泡软，酸菜切丝，生姜切片，小葱切段，大蒜切末，香菜切段  
2、五花肉冷水下锅，加入一半生姜和小葱，以及花椒和八角，烧开后转小火煮30分钟  
3、捞出五花肉放凉后切成薄片，煮肉的原汤过滤备用  
4、锅中加入适量油，放入剩余的生姜、小葱和蒜末炒香，再放入酸菜翻炒均匀  
5、倒入煮肉原汤烧开，加入盐和白胡椒粉  
6、放入粉丝和肉片，小火煮5分钟  
7、撒上香菜后出锅
