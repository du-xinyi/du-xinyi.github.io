---
title: "白灼虾"
---

| 主料                     |
| :----------------------- | ----: |
| 鲜活海虾（每斤20～30尾） | 650克 |

| 辅料 |
| :--- | ---: |
| 生姜 | 15克 |
| 小葱 | 10克 |

| 调料   |
| :----- | -----: |
| 清水   | 2500克 |
| 盐     |   10克 |
| 白灼汁 |   适量 |

制作过程：  
1、海虾洗净，生姜切片，小葱打结  
2、锅中加入清水、姜片、葱结和盐，加热至约90℃，锅边连续冒出小泡  
3、放入海虾，轻轻拨散，加热30秒后关火，浸泡1分30秒  
4、取最大的一只虾，剥开查看最厚处，虾肉变白且不透明后捞出装盘；若中心仍透明，开小火继续加热至熟透  
5、搭配白灼汁食用
