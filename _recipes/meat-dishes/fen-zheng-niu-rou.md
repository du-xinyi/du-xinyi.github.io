---
title: "粉蒸牛肉"
---

| 主料             |
| :--------------- | ----: |
| 牛腱子肉/牛里脊 | 500克 |

| 米粉   |
| :----- | ----: |
| 大米   | 120克 |
| 糯米   |  30克 |
| 花椒   |   3克 |
| 八角   |   1个 |
| 小茴香 |   3克 |
| 桂皮   |   1克 |

| 辅料       |
| :--------- | ----: |
| 红薯/土豆 | 200克 |

| 调料   |
| :----- | ---: |
| 豆腐乳 | 20克 |
| 辣椒面 | 10克 |
| 白酒   |  5克 |
| 豆瓣酱 | 10克 |
| 生抽   | 10克 |
| 料酒   | 10克 |
| 白糖   |  5克 |
| 葱姜水 | 60克 |
| 红油   | 15克 |

制作过程：  
1、大米和糯米洗净后沥干水分  
2、锅中放入大米和糯米，中火炒干水分，加入花椒、八角、小茴香和桂皮，小火炒至米粒微黄  
3、将炒好的米和香料彻底放凉，打成带有细小颗粒的米粉  
4、牛肉切片，加入豆腐乳、生抽、料酒和白糖，分次加入葱姜水抓拌至吸收  
5、锅中加入适量油，放入豆瓣酱炒香，再加入用5克白酒润湿的辣椒面，炒匀后倒入牛肉中  
6、牛肉分次加入米粉拌匀，再加入红油抓匀  
7、红薯/土豆切片后铺在碗底，码上牛肉  
8、蒸锅上汽后放入，中小火蒸50分钟，撒上葱花后出锅
