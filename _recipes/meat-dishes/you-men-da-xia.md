---
title: "油焖大虾"
---

| 主料   |
| :----- | ----: |
| 黑虎虾 | 500克 |

| 料油 |
| :--- | ---: |
| 大葱 | 30克 |
| 生姜 | 10克 |
| 花椒 |  5克 |

| 料汁 |
| :--- | ----: |
| 料酒 |  30克 |
| 冰糖 |  10克 |
| 姜末 |   5克 |
| 盐   |   3克 |
| 清水 | 100克 |

制作过程：  
1、虾剪去虾枪、虾须和尾尖，去除沙包和虾线，从背部剖开  
2、料油中的生姜切片，大葱切段，料汁中的姜末切好备用  
3、锅中加入适量油，烧至4成热后转小火，放入花椒、姜片和葱段，炸至葱段微黄后捞出料渣  
4、盛出10克料油备用，锅中留下其余料油，放入虾，小火煎至两面变色并析出虾油  
5、加入料酒、冰糖、姜末、盐和清水，大火烧开后转中火加盖焖3分钟  
6、将虾盛出摆盘，锅中汤汁加入预留的料油，大火收至浓稠后淋在虾上
