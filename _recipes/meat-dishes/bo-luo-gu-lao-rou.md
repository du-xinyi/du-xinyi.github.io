---
title: "菠萝咕咾肉"
---

| 主料   |
| :----- | ----: |
| 五花肉 | 300克 |

| 辅料   |
| :----- | ----: |
| 菠萝   | 150克 |
| 青椒   |  50克 |
| 红椒   |  50克 |
| 胡萝卜 |  50克 |
| 黄瓜   |  50克 |
| 大蒜   |   5克 |
| 小葱   |   5克 |

| 腌料     |
| :------- | ----: |
| 生姜     |   5克 |
| 盐       |   2克 |
| 白胡椒粉 | 0.5克 |
| 料酒     |  10克 |
| 香油     |   5克 |
| 鸡蛋     |   1个 |
| 玉米淀粉 |  60克 |

| 料汁     |
| :------- | ---: |
| 番茄沙司 | 50克 |
| 白糖     | 20克 |
| 白醋     | 15克 |
| 盐       |  1克 |
| 清水     | 30克 |

制作过程：  
1、五花肉去皮后切片，菠萝、青椒和红椒切块，胡萝卜和黄瓜切滚刀块，生姜和大蒜切末，小葱切花  
2、肉片加入姜末、盐、白胡椒粉、料酒和香油，抓拌均匀后腌制10分钟  
3、加入鸡蛋抓匀，再加入玉米淀粉抓匀，将肉片分别团成球状  
4、锅中加入适量油，烧至5成热，放入肉团炸至定型并熟透后捞出  
5、胡萝卜下锅炸至断生后捞出，黄瓜快速过油后捞出  
6、油温升至7成热，放入肉团复炸30秒，炸至金黄酥脆后捞出  
7、锅中留少许底油，放入蒜末和葱花炒香，加入番茄沙司、白糖、白醋、盐和清水，烧开后加入水淀粉收浓  
8、放入炸好的肉团、菠萝、青椒、红椒、胡萝卜和黄瓜，大火快速翻炒至均匀裹汁后出锅
