---
title: "牛排北非蛋"
---

| 主料 |
| :--- | ----: |
| 牛排 | 250克 |
| 鸡蛋 |   2个 |

| 辅料   |
| :----- | ----: |
| 番茄   | 300克 |
| 红甜椒 | 100克 |
| 黄洋葱 |  80克 |
| 大蒜   |  10克 |
| 欧芹   |   5克 |

| 调料     |
| :------- | ---: |
| 番茄酱   | 30克 |
| 清水     | 50克 |
| 孜然粉   |  2克 |
| 甜椒粉   |  2克 |
| 辣椒粉   |  1克 |
| 盐       |  5克 |
| 黑胡椒碎 |  1克 |
| 橄榄油   | 15克 |

制作过程：  
1、牛排擦干表面水分，番茄切碎，红甜椒和洋葱切丁，大蒜切末，欧芹切碎  
2、牛排两面撒上2克盐和黑胡椒碎，静置10分钟  
3、锅烧热后加入10克橄榄油，放入洋葱和红甜椒炒软，再加入蒜末炒香  
4、加入番茄酱、孜然粉、甜椒粉和辣椒粉，小火炒出香味  
5、加入番茄、清水和剩余的盐，小火煮10分钟，将酱汁收至浓稠  
6、在酱汁中挖出两个凹槽，打入鸡蛋，加盖小火焖至蛋白凝固、蛋黄保持流心  
7、焖蛋的同时，另取一锅烧热后加入剩余的橄榄油，放入牛排，每面煎约2分钟，煎至中心温度约52℃后盛出，静置5分钟  
8、牛排切片后放在酱汁表面，撒上欧芹后出锅
