---
title: "咸烧白"
---

| 主料   |
| :----- | ----: |
| 五花肉 | 500克 |
| 芽菜   | 200克 |

| 辅料       |
| :--------- | ---: |
| 生姜       | 10克 |
| 大蒜       | 10克 |
| 花椒       |  3克 |
| 子弹头辣椒 |  5克 |
| 八角       |  2个 |
| 小葱       | 10克 |

| 料汁 |
| :--- | ---: |
| 盐   |  2克 |
| 味精 |  3克 |
| 白糖 |  5克 |
| 白酒 | 10克 |
| 料酒 | 20克 |
| 老抽 |  5克 |
| 生抽 | 15克 |
| 糖色 | 10克 |

制作过程：  
1、锅烧热后将五花肉皮烙至金黄色，取出洗净  
2、五花肉冷水下锅，加入料酒、少量花椒、姜片和葱段，煮至筷子能够扎入后捞出  
3、芽菜洗净后切碎，生姜和大蒜切末，小葱切花  
4、趁热在肉皮上均匀涂抹生抽，晾干表面水分  
5、锅中加入适量油，烧至7成热，五花肉皮朝下炸至金黄，立即放回煮肉的原汤中浸泡10分钟  
6、五花肉切片，加入料汁拌匀，肉皮朝下整齐码入碗中  
7、锅中加入少许油，放入姜末、蒜末、花椒、辣椒和八角炒香，再加入芽菜炒干水分  
8、将炒好的芽菜铺在肉片上，淋入剩余的料汁  
9、蒸锅上汽后放入，大火蒸60分钟  
10、倒扣装盘，撒上葱花后食用
