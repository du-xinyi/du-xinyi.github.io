---
title: "黑椒牛肉粒"
---

| 主料   |
| :----- | ----: |
| 牛里脊 | 300克 |

| 辅料   |
| :----- | ----: |
| 洋葱   | 100克 |
| 青椒   |  50克 |
| 红甜椒 |  50克 |
| 大蒜   |  10克 |

| 料汁     |
| :------- | ---: |
| 生抽     | 10克 |
| 蚝油     | 10克 |
| 老抽     |  2克 |
| 白糖     |  3克 |
| 黑胡椒碎 |  2克 |
| 清水     | 30克 |
| 玉米淀粉 |  2克 |

制作过程：  
1、牛里脊擦干后切成约2厘米的块，洋葱、青椒和红甜椒切块，大蒜切末  
2、料汁混合均匀  
3、锅烧热后加入适量油，放入牛肉粒，中大火煎至表面上色后盛出  
4、锅中留少许底油，放入洋葱、青椒和红甜椒炒至断生，加入蒜末炒香  
5、料汁再次搅匀后倒入锅中，煮至略微浓稠  
6、放回牛肉粒，翻炒至熟度合适、均匀裹上料汁后出锅
