---
title: "葱烧海参"
---

| 主料     |
| :------- | ----: |
| 水发海参 | 500克 |
| 大葱     | 150克 |
| 上海青   | 100克 |
| 鸡架猪骨清汤     | 600克 |

| 辅料 |
| :--- | ---: |
| 生姜 | 10克 |

| 调料     |
| :------- | ----: |
| 黄酒     |  30克 |
| 生抽     |  20克 |
| 老抽     |   5克 |
| 白糖     |  10克 |
| 盐       |   3克 |
| 白胡椒粉 | 0.5克 |

制作过程：  
1、海参剖开后清理干净，大葱切段并在两侧切斜刀，生姜切片  
2、海参冷水下锅，加入一半姜片和15克黄酒，烧开后煮2分钟，捞出冲洗干净  
3、锅中加入适量油，放入葱段，小火炸至金黄后捞出，锅中的葱油保留  
4、锅中留适量葱油，放入剩余的姜片炒香，加入鸡架猪骨清汤、海参、剩余的黄酒、生抽、老抽、白糖、盐和白胡椒粉  
5、烧开后转小火煨20分钟，加入炸好的葱段，继续煨5分钟  
6、上海青焯水后摆入盘中，海参和葱段盛出装盘  
7、锅中汤汁加入水淀粉收至浓稠，加入葱油搅匀，淋在海参上
