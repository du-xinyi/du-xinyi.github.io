---
title: "酒香花蛤"
---

| 主料 |
| :--- | -----: |
| 花蛤 | 1500克 |

| 辅料 |
| :--- | ---: |
| 青椒 | 50克 |
| 红椒 | 50克 |
| 小葱 | 20克 |
| 生姜 | 10克 |
| 大蒜 | 20克 |
| 花椒 |  3克 |

| 调料       |
| :--------- | ----: |
| 郫县豆瓣酱 |  20克 |
| 白酒       |  50克 |
| 生抽       |  15克 |
| 蚝油       |   5克 |
| 料酒       |   5克 |
| 白糖       |   5克 |
| 清水       | 100克 |

制作过程：  
1、花蛤用淡盐水浸泡吐沙，捞出后反复冲洗干净  
2、青椒和红椒切圈，小葱葱白切段、葱叶切花，生姜切片，大蒜切末，除豆瓣酱和白酒外的调料混合均匀  
3、锅中加入适量油，放入花椒小火炒香后捞出  
4、放入葱段和姜片炒香，再加入豆瓣酱，小火炒出红油  
5、放入花蛤，大火翻炒至陆续开口  
6、沿锅边淋入白酒，翻炒至酒气挥发  
7、倒入调好的料汁，加入水淀粉后大火翻炒收汁  
8、加入青椒、红椒和蒜末，翻炒至断生，撒上葱花后出锅

P.S.  
1、烹调后仍未开口的花蛤不要食用
