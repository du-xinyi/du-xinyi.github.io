---
title: "榴莲炖鸡"
---

| 主料     |
| :------- | ----: |
| 鸡肉     | 500克 |
| 榴莲果肉 |  80克 |

| 辅料       |
| :--------- | ----: |
| 榴莲壳白瓤 | 200克 |
| 红枣       |  10克 |
| 枸杞       |  10克 |
| 生姜       |  10克 |

| 调料 |
| :--- | -----: |
| 盐   |    4克 |
| 清水 | 1000克 |

制作过程：  
1、鸡肉剁块，榴莲壳取白瓤后切块，红枣去核，生姜切片  
2、鸡肉冷水下锅，烧开后撇去浮沫，捞出冲洗干净  
3、鸡肉、榴莲壳白瓤、红枣和姜片放入锅中，加入清水烧开  
4、转小火加盖炖煮60分钟  
5、榴莲果肉掰成大块，与枸杞一同放入，继续炖煮15分钟  
6、加入盐调味后出锅
