---
title: "锅巴虾仁（桃花泛）"
---

| 主料 |
| :--- | ----: |
| 虾仁 | 200克 |
| 锅巴 | 200克 |

| 辅料   |
| :----- | ----: |
| 番茄   | 150克 |
| 胡萝卜 |  50克 |
| 豌豆   |  30克 |
| 大蒜   |   5克 |
| 生姜   |   5克 |
| 小葱   |   5克 |
| 鸡蛋清 |   1个 |

| 调料     |
| :------- | ----: |
| 番茄酱   |  20克 |
| 白糖     |  15克 |
| 白醋     |  10克 |
| 盐       |   3克 |
| 白胡椒粉 | 0.5克 |
| 玉米淀粉 |  10克 |
| 清水     | 200克 |

制作过程：  
1、虾仁开背，胡萝卜切块，番茄切丁，大蒜切片，生姜切末，小葱切花  
2、鸡蛋清加入玉米淀粉和1克盐，搅拌至黏稠，放入虾仁抓拌上劲  
3、胡萝卜和豌豆焯水，虾仁滑熟后捞出  
4、锅中加入适量油，放入姜末、蒜片和葱花炒香，再加入番茄酱和番茄，炒至番茄软烂  
5、加入清水、白糖、剩余的盐和白胡椒粉，放入胡萝卜和豌豆，煮至汤色明亮  
6、加入白醋、虾仁和水淀粉，将汤汁收至略微浓稠  
7、锅巴炸至酥脆后立即装盘，趁热淋上虾仁和汤汁
