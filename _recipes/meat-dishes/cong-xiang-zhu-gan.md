---
title: "葱香猪肝"
---

| 主料 |
| :--- | ----: |
| 猪肝 | 400克 |
| 小葱 |   1把 |

| 腌料     |
| :------- | ---: |
| 蚝油     |  4克 |
| 胡椒粉   |  2克 |
| 生抽     |  3克 |
| 玉米淀粉 | 40克 |

| 料汁   |
| :----- | ----: |
| 生抽   |  10克 |
| 蚝油   |   3克 |
| 白糖   |   2克 |
| 味精   |   2克 |
| 胡椒粉 |   2克 |
| 老抽   |   2克 |
| 啤酒   | 150克 |

制作过程：  
1、猪肝切成约3毫米厚的片，小葱的葱白和葱叶分别切碎  
2、将猪肝洗净后加入腌料混合均匀，料汁混合均匀  
3、将锅烧至微微发红后离火，加入宽油，将猪肝下锅  
4、猪肝定型后稍微加热，滑至7成熟后捞出控油  
5、热锅，下入葱白小火爆香，倒入料汁小火烧开，加入水淀粉收浓  
6、汤汁收浓后加入猪肝，翻炒均匀后撒上葱花，淋上少许热油

P.S.  
1、猪肝未定型前切忌翻动，否则极易脱粉
