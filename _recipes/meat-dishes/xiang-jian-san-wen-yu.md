---
title: "香煎三文鱼"
---

| 主料       |
| :--------- | ----: |
| 带皮三文鱼 | 250克 |

| 辅料       |
| :--------- | ---: |
| 大蒜       |  2瓣 |
| 百里香     |  1枝 |
| 黄油       | 10克 |
| 橄榄油     |  5克 |
| 柠檬黄油汁 | 适量 |

| 调料     |
| :------- | ----: |
| 盐       |   2克 |
| 黑胡椒粉 | 0.5克 |

制作过程：  
1、三文鱼去除鱼刺，用厨房纸吸干表面水分，大蒜拍破  
2、三文鱼两面均匀撒上盐和黑胡椒粉  
3、平底锅中火烧热后加入橄榄油，三文鱼鱼皮朝下放入锅中，轻压20秒使鱼皮贴合锅底  
4、转中小火煎4分钟，待鱼皮金黄酥脆、鱼肉侧面约三分之二变色后翻面  
5、加入大蒜、百里香和黄油，待黄油融化后不断淋在鱼肉表面，继续煎1分钟  
6、将三文鱼盛出静置2分钟，搭配柠檬黄油汁装盘

P.S.  
1、三文鱼下锅前应充分吸干水分，否则鱼皮不易煎脆  
2、柠檬黄油汁应放在盘底或鱼肉旁边，避免鱼皮回软
