---
title: "仔姜鲜锅兔"
---

| 主料 |
| :--- | -----: |
| 兔肉 | 1000克 |

| 辅料   |
| :----- | ----: |
| 仔姜   | 300克 |
| 二荆条 |  50克 |
| 小米辣 |  50克 |

| 料头       |
| :--------- | ---: |
| 生姜       | 20克 |
| 大蒜       | 20克 |
| 青花椒     |  5克 |
| 郫县豆瓣酱 | 20克 |

| 腌料     |
| :------- | ---: |
| 盐       |  3克 |
| 白胡椒粉 |  1克 |
| 料酒     | 20克 |
| 红薯淀粉 | 25克 |

| 汤底         |
| :----------- | ----: |
| 鸡架猪骨清汤 | 500克 |
| 生抽         |  15克 |
| 盐           |   3克 |
| 白糖         |   5克 |
| 味精         |   2克 |
| 白胡椒粉     |   1克 |
| 红油         |  20克 |

制作过程：  
1、兔肉剁成小块，加入腌料抓拌均匀，腌制15分钟  
2、生姜和大蒜切末，小米辣剁碎，二荆条切圈，仔姜切丝  
3、锅中加入适量油，烧至4成热，分两批放入兔肉滑油，待表面定型后轻轻推散，滑至八成熟后捞出  
4、锅中留少许底油，放入青花椒、姜末和蒜末炒香，再加入一半小米辣和一半仔姜炒出香味  
5、加入豆瓣酱，小火炒出红油  
6、倒入鸡架猪骨清汤，加入生抽、盐、白糖、味精和白胡椒粉，烧开后放入兔肉，中火煮3分钟  
7、加入剩余的小米辣、仔姜和二荆条，继续煮2分钟  
8、加入红油搅匀，大火将汤汁略微收浓后出锅
