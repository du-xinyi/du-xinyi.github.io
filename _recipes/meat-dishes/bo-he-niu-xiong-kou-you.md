---
title: "薄荷牛胸口油"
---

| 主料     |
| :------- | ----: |
| 牛胸口油 | 300克 |

| 辅料     |
| :------- | ---: |
| 鲜薄荷叶 | 30克 |
| 大蒜     | 15克 |
| 生姜     | 10克 |
| 干辣椒   |  5克 |
| 泡椒     |  5克 |
| 花椒     |  1克 |

| 料汁   |
| :----- | ---: |
| 生抽   | 15克 |
| 蚝油   | 10克 |
| 白糖   |  5克 |
| 花椒粉 |  1克 |
| 孜然粉 |  1克 |

制作过程：  
1、牛胸口油冷冻至稍硬后切薄片，薄荷叶洗净并充分晾干表面水分，大蒜切片，生姜切丝，干辣椒切段  
2、料汁混合均匀  
3、锅中加入适量油，烧至五成热，分批放入薄荷叶，炸至气泡明显减少后立即捞出沥油  
4、锅中留少许底油，放入牛胸口油，中火煸出油脂，至边缘微黄后盛出  
5、倒出多余油脂，留少许底油，放入姜丝、蒜片、干辣椒、泡椒和花椒，小火炒香  
6、放回牛胸口油，倒入料汁，大火翻炒至熟透并均匀裹汁  
7、加入炸好的薄荷叶，快速翻拌均匀后出锅
