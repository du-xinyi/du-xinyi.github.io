---
title: "酒香肥肠"
---

| 主料 |
| :--- | ----: |
| 肥肠 | 500克 |

| 辅料   |
| :----- | ---: |
| 生姜   | 30克 |
| 大葱   | 30克 |
| 小葱   | 20克 |
| 红泡椒 | 30克 |

| 香料 |
| :--- | ---: |
| 草果 |  2颗 |
| 八角 |  2颗 |
| 桂皮 |  2克 |
| 香叶 |  2片 |
| 花椒 |  3克 |

| 调料       |
| :--------- | -----: |
| 郫县豆瓣酱 |   20克 |
| 白酒       |   50克 |
| 红油       |   20克 |
| 生抽       |   15克 |
| 老抽       |    5克 |
| 盐         |    3克 |
| 白胡椒粉   |    1克 |
| 清水       | 1000克 |

制作过程：  
1、肥肠用温水清洗两遍后剪开，去除多余油脂  
2、加入少量盐和20克白酒，抓洗后冲洗干净，切成大块  
3、生姜切片，大葱和红泡椒切段，小葱一半切段、一半切花，草果去籽  
4、肥肠冷水下锅，烧开后煮3分钟，捞出冲洗干净  
5、锅中加入适量油，放入花椒和香料炒香，再加入大葱、生姜、红泡椒和豆瓣酱，小火炒出红油  
6、放入肥肠，小火翻炒5分钟，沿锅边淋入剩余的白酒，翻炒至酒气挥发  
7、加入清水、红油、生抽、老抽、盐和白胡椒粉，烧开后转小火炖90～120分钟，直至肥肠软熟  
8、砂锅底部铺入小葱段，放入肥肠并倒入原汤，烧开后撒上葱花

P.S.  
1、肥肠应保持小火炖煮，并以实际软烂程度决定出锅时间
