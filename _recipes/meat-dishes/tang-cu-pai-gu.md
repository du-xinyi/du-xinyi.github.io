---
title: "糖醋排骨"
---

| 主料 |
| :--- | ----: |
| 排骨 | 500克 |

| 腌料     |
| :------- | ----: |
| 鸡蛋     |   1个 |
| 玉米淀粉 |  30克 |
| 盐       |   2克 |
| 白胡椒粉 | 0.5克 |

| 料汁   |
| :----- | ---: |
| 白糖   | 40克 |
| 香醋   | 30克 |
| 盐     |  1克 |
| 清水   | 30克 |

| 辅料     |
| :------- | ---: |
| 生姜     | 10克 |
| 熟白芝麻 |  5克 |
| 面粉     | 适量 |

制作过程：  
1、排骨剁成约4厘米长的段，加入少量面粉和清水抓洗，再用清水冲洗干净并挤干水分  
2、排骨加入鸡蛋、盐、白胡椒粉和玉米淀粉，抓拌均匀后腌制15分钟  
3、生姜切末，白糖、香醋、盐和清水混合成料汁  
4、锅中加入适量油，烧至5成热，放入排骨，中小火炸6～8分钟，直至内部熟透后捞出  
5、油温升至7成热，放入排骨复炸30秒，捞出控油  
6、锅中留少许底油，放入姜末炒香，倒入料汁，小火煮至白糖融化  
7、加入水淀粉将料汁收浓，再加入适量明油搅匀  
8、放入排骨快速翻炒至均匀裹汁，撒上熟白芝麻后出锅
