---
title: "煎酿三宝"
---

| 主料   |
| :----- | ----: |
| 猪肉末 | 300克 |
| 青椒   | 150克 |
| 茄子   | 150克 |
| 苦瓜   | 150克 |

| 辅料 |
| :--- | ---: |
| 生姜 |  5克 |
| 小葱 | 10克 |

| 腌料     |
| :------- | ----: |
| 生抽     |  10克 |
| 料酒     |  10克 |
| 生粉     |  10克 |
| 盐       |   1克 |
| 白胡椒粉 | 0.5克 |

| 料汁 |
| :--- | ----: |
| 生抽 |  10克 |
| 老抽 |   2克 |
| 蚝油 |  10克 |
| 白糖 |   3克 |
| 清水 | 200克 |

制作过程：  
1、青椒去蒂去籽，纵向对半切开；茄子切成2厘米厚的片，中间切一刀但不切断；苦瓜切成2厘米厚的圈，去掉瓜瓤，生姜切末，小葱切花  
2、苦瓜放入沸水中焯水2分钟，捞出沥干，青椒和茄子擦干水分  
3、猪肉末中加入姜末、葱花和腌料，沿同一方向搅拌至黏稠  
4、青椒内侧、茄子夹层和苦瓜圈内壁薄薄撒上少许生粉，填入肉馅并压实  
5、料汁混合均匀  
6、锅中加入适量油，分批放入酿好的三宝，中小火煎至两面微黄，青椒先煎肉馅一面  
7、将三宝放回锅中，倒入料汁，烧开后加盖小火焖12分钟，至肉馅熟透、蔬菜软熟  
8、开盖稍收汤汁，淋入少量水淀粉勾薄芡，将芡汁淋在三宝上，盛出装盘
