---
title: "焦溜丸子"
---

| 主料   |
| :----- | ----: |
| 五花肉 | 500克 |
| 青蒜苗 |   1根 |
| 木耳   |  适量 |

| 腌料     |
| :------- | ----: |
| 葱姜水   | 100克 |
| 盐       |   2克 |
| 黄酱     |   5克 |
| 玉米淀粉 |  80克 |
| 黄酒     |  少许 |
| 五香粉   |  少许 |
| 香油     |  少许 |

| 料汁   |
| :----- | ---: |
| 葱白   |  5克 |
| 姜     |  5克 |
| 蒜     |  5克 |
| 黄酒   | 10克 |
| 生抽   | 20克 |
| 老抽   | 少许 |
| 米醋   |  5克 |
| 盐     |  2克 |
| 鸡架猪骨清汤   | 50克 |
| 胡椒粉 | 少许 |

制作过程：  
1、五花肉去皮后剁成馅，逐步搅打加入葱姜水  
2、肉馅充分吸收水分后，加入其余腌料搅打均匀，冷藏2小时  
3、蒜苗切段，木耳焯水，葱白、姜、蒜切粒后与其余料汁混合均匀  
4、锅中加入适量油，烧至5成热，将肉馅挤成丸子依次下入，炸至表面金黄、内部熟透后捞出控油  
5、锅中加入适量油，烧至7成热，下入丸子，炸至表面焦黄后捞出控油  
6、锅中加入少许油，倒入料汁、蒜苗和木耳，加入水淀粉收浓后浇入少许热油  
7、加入丸子翻炒均匀
