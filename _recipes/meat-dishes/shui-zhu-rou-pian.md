---
title: "水煮肉片"
---

| 主料   |
| :----- | ----: |
| 里脊肉 | 300克 |

| 辅料 |
| :--- | ----: |
| 豆芽 | 100克 |
| 凤尾 | 100克 |
| 蒜苗 |  30克 |
| 芹菜 |  50克 |
| 大蒜 |  20克 |
| 生姜 |  10克 |
| 泡椒 |  20克 |

| 腌料     |
| :------- | ----: |
| 盐       |   2克 |
| 生抽     |  10克 |
| 料酒     |  10克 |
| 白胡椒粉 | 0.5克 |
| 鸡蛋清   |   1个 |
| 红薯淀粉 |  15克 |

| 汤底     |
| :------- | ----: |
| 豆瓣酱   |  20克 |
| 清水     | 600克 |
| 盐       |   3克 |
| 白糖     |   3克 |
| 味精     |   2克 |
| 白胡椒粉 | 0.5克 |

| 刀口料   |
| :------- | ---: |
| 刀口辣椒 | 20克 |
| 蒜蓉     | 10克 |
| 葱花     | 10克 |

制作过程：  
1、里脊肉切成薄片，加入腌料，搅打上劲  
2、凤尾切条，蒜苗和芹菜切段，辅料中的大蒜、生姜和泡椒切末，刀口料中的蒜蓉和葱花另外备好  
3、锅中加入油，放入豆芽、凤尾、蒜苗和芹菜，大火炒至断生，加入少许盐后盛入盆底  
4、锅中加入油，放入姜末、蒜末和泡椒炒香，再加入豆瓣酱，小火炒出红油  
5、加入清水烧开，放入汤底中的盐、白糖、味精和白胡椒粉，再加入水淀粉使汤汁略微浓稠  
6、转小火，将肉片逐片放入，待全部定型后轻轻推散，煮至刚熟  
7、将肉片和适量原汤盛入盆中，撒上刀口辣椒、蒜蓉和葱花  
8、油烧至7成热，均匀淋在刀口料上
