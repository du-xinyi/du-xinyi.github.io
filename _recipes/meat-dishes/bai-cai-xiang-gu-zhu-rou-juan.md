---
title: "白菜香菇猪肉卷"
---

| 主料   |
| :----- | ----: |
| 白菜叶 |   8片 |
| 猪肉馅 | 300克 |
| 鲜香菇 | 100克 |

| 辅料 |
| :--- | ---: |
| 生姜 |  5克 |
| 小葱 | 10克 |

| 调料     |
| :------- | ----: |
| 生抽     |  15克 |
| 蚝油     |  10克 |
| 盐       |   1克 |
| 白糖     |   2克 |
| 白胡椒粉 | 0.5克 |
| 玉米淀粉 |   5克 |
| 香油     |   5克 |

制作过程：  
1、白菜叶洗净，削薄较厚的菜帮，香菇去蒂切末，生姜切末，小葱切葱花  
2、白菜叶放入沸水中煮至变软，捞出过凉后沥干水分  
3、猪肉馅中加入香菇、姜末、葱花和调料，沿同一方向搅拌至黏稠  
4、白菜叶铺平，放上肉馅，两侧向内折起后卷紧，收口朝下放入盘中  
5、蒸锅上汽后放入，中火蒸20分钟，至肉馅熟透后出锅
