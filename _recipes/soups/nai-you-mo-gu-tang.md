---
title: "奶油蘑菇汤"
---

| 主料             |
| :--------------- | ----: |
| 口蘑             | 150克 |
| 凉牛奶           | 250克 |
| 鸡肉清汤/蔬菜清汤 | 300克 |
| 淡奶油           |  50克 |

| 辅料     |
| :------- | ---: |
| 黄油     | 30克 |
| 面粉     | 20克 |
| 香叶     |  1片 |
| 白葡萄酒 | 15克 |

| 调料     |
| :------- | ----: |
| 盐       |   2克 |
| 白糖     |   1克 |
| 白胡椒粉 | 0.3克 |

制作过程：  
1、口蘑清理干净后切片  
2、锅中加入20克黄油，小火融化后加入面粉，翻炒3～4分钟  
3、加入香叶，继续炒至面粉微黄、质地松散且黄油略微析出  
4、分次加入凉牛奶，每次搅拌均匀后再继续加入，搅拌至汤汁黏稠  
5、分次加入鸡肉清汤或蔬菜清汤，搅拌均匀后取出香叶，将汤底过筛备用  
6、锅中加入剩余的10克黄油，放入口蘑片炒软  
7、加入白葡萄酒，煮至酒液基本收干，倒入汤底并搅拌均匀  
8、小火加热，加入盐、白糖和白胡椒粉，持续搅拌至煮开，转最小火煮5分钟  
9、加入淡奶油搅拌均匀，继续加热2分钟后出锅

P.S.  
1、鸡肉清汤风味浓郁，蔬菜清汤更为清爽  
2、白葡萄酒建议选用酸度较低的类型  
3、喜欢细腻汤体时，可将三分之二的口蘑与少量汤底打成蓉，其余保留切片增加口感
