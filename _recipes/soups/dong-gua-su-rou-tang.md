---
title: "冬瓜酥肉汤"
---

| 主料 |
| :--- | ----: |
| 冬瓜 | 600克 |
| 酥肉 | 200克 |
| 紫菜 |  10克 |

| 辅料 |
| :--- | ---: |
| 生姜 |  5克 |

| 调料     |
| :------- | -----: |
| 清水     | 1000克 |
| 盐       |    6克 |
| 白胡椒粉 |  0.5克 |

制作过程：  
1、冬瓜去皮去瓤后切片，紫菜洗净，酥肉切段，生姜切末  
2、锅中加入清水，烧开后放入酥肉，大火煮1分钟  
3、转中小火煮8分钟，加入姜末、紫菜和冬瓜  
4、再次烧开后转小火煮5分钟  
5、加入盐和白胡椒粉，搅拌均匀后出锅
