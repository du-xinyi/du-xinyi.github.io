---
title: "罗宋汤"
---

| 主料   |
| :----- | ----: |
| 牛腩   | 500克 |
| 番茄   | 400克 |
| 卷心菜 | 250克 |
| 土豆   | 250克 |

| 辅料   |
| :----- | ----: |
| 黄洋葱 | 150克 |
| 胡萝卜 | 100克 |
| 西芹   |  50克 |
| 大蒜   |   5克 |

| 调料     |
| :------- | ---: |
| 番茄酱   | 50克 |
| 黄油     | 30克 |
| 面粉     | 15克 |
| 白糖     | 10克 |
| 盐       |  5克 |
| 黑胡椒碎 |  1克 |
| 香叶     |  2片 |

制作过程：  
1、牛腩切块，番茄去皮去蒂后切块，土豆和胡萝卜去皮后切块，卷心菜切片，洋葱和西芹切碎，大蒜切末  
2、牛腩冷水下锅，烧开后撇去浮沫，捞出冲洗干净  
3、牛腩放入锅中，加入适量清水和香叶烧开，转小火加盖炖煮60分钟  
4、另起锅加入20克黄油，融化后放入洋葱、胡萝卜、西芹和蒜末，炒至洋葱变软  
5、加入番茄酱炒出香味，再放入番茄，炒至软烂出汁  
6、将炒好的蔬菜放入牛肉汤中，加入土豆和卷心菜，烧开后转小火煮30分钟  
7、锅中加入剩余的黄油，小火融化后加入面粉，翻炒至均匀顺滑并呈微黄色  
8、分次加入适量原汤，将油面酱搅拌至无颗粒，再倒回汤中搅拌均匀  
9、加入白糖、盐和黑胡椒碎，继续煮5分钟，待汤汁略微浓稠后出锅
