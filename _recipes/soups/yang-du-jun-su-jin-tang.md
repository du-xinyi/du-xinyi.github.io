---
title: "羊肚菌素金汤"
---

| 主料     |
| :------- | ----: |
| 干羊肚菌 |   8克 |
| 山药     | 100克 |
| 口蘑     | 150克 |
| 鲜豌豆   |  50克 |

| 金汤   |
| :----- | ----: |
| 南瓜   | 200克 |
| 生腰果 |  30克 |
| 清水   | 500克 |

| 辅料 |
| :--- | ---: |
| 生姜 |  5克 |

| 调料 |
| :--- | ----: |
| 清水 | 200克 |
| 盐   |   5克 |

制作过程：  
1、羊肚菌剪去底部带泥沙的部分，冲洗干净，用200克温水泡发，泡菌水过滤备用  
2、山药去皮切片，口蘑洗净切片，南瓜去皮去瓤切块，生姜切片  
3、锅中加入南瓜、生腰果和500克清水，烧开后加盖小火煮15分钟，至南瓜软熟后连汤打细  
4、另起锅加入少许油，放入姜片炒香，加入口蘑翻炒出香味  
5、加入羊肚菌、山药和泡菌水，烧开后加盖小火煮10分钟，水量不足时补适量开水  
6、倒入金汤，加入豌豆，煮开后小火继续煮5分钟，至食材熟透  
7、加入盐，搅拌均匀后出锅
