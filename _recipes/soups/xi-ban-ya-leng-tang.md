---
title: "西班牙冷汤"
---

| 主料 | 用量 |
| :--- | ---: |
| 番茄 | 500克 |
| 黄瓜 | 100克 |
| 青椒 | 60克 |

| 辅料 | 用量 |
| :--- | ---: |
| 红洋葱 | 30克 |
| 大蒜 | 3克 |
| 白面包 | 30克 |

| 调料 | 用量 |
| :--- | ---: |
| 橄榄油 | 30克 |
| 雪莉醋 | 15克 |
| 盐 | 3克 |

制作过程：  
1、番茄去蒂切块，黄瓜去皮切块，青椒去蒂去籽切块，洋葱和大蒜切碎，白面包撕成小块  
2、蔬菜中加入盐和雪莉醋，拌匀后静置30分钟  
3、加入白面包，拌匀后浸泡至软  
4、用料理机搅打细腻，分次加入25克橄榄油，继续搅打至均匀顺滑  
5、过筛后放入冰箱冷藏2小时  
6、取出搅匀，盛入碗中，淋入剩余的橄榄油
