---
title: "胡辣汤"
---

| 主料       |
| :--------- | ----: |
| 牛肉       | 150克 |
| 生花生米   |  80克 |
| 粉丝       |  50克 |
| 水洗面筋   | 150克 |
| 水发海带   |  50克 |
| 水发木耳   |  50克 |
| 水发黄花菜 |  30克 |
| 香菇       |  50克 |
| 平菇       |  50克 |

| 汤底           |
| :------------- | -----: |
| 清水           | 1500克 |
| 沉淀后的浓面浆 |  300克 |
| 生抽           |   15克 |
| 老抽           |    5克 |
| 黄酒           |   10克 |
| 盐             |   10克 |
| 白胡椒粉       |    5克 |
| 辣椒粉         |    2克 |
| 五香粉         |  0.5克 |

| 辅料 |
| :--- | ---: |
| 小葱 | 10克 |
| 生姜 | 10克 |

制作过程：  
1、生花生米提前浸泡4小时，放入清水中煮30分钟，捞出备用，粉丝泡软  
2、牛肉切片，海带、木耳、黄花菜、香菇和平菇切成适口大小，小葱和生姜切末  
3、锅中加入适量油，放入葱末和姜末炒香，再放入牛肉，加入黄酒和生抽炒至变色  
4、加入清水和花生米，烧开后转小火煮10分钟  
5、加入粉丝、海带、木耳、黄花菜、香菇和平菇，继续煮5分钟  
6、加入盐、白胡椒粉、辣椒粉、五香粉和老抽，搅拌均匀  
7、将面筋揪成小片放入，煮至面筋浮起  
8、面浆静置沉淀后倒去上层清水，分次加入浓面浆，边加边搅拌，直至汤汁达到需要的浓稠度
