---
title: "白菜豆腐汤"
---

| 主料   |
| :----- | ----: |
| 白菜   | 300克 |
| 嫩豆腐 | 300克 |

| 辅料 |
| :--- | ---: |
| 生姜 |  5克 |
| 小葱 | 10克 |

| 调料     |
| :------- | ----: |
| 清水     | 800克 |
| 盐       |   4克 |
| 白胡椒粉 | 0.5克 |
| 香油     |   3克 |

制作过程：  
1、白菜洗净切块，菜帮和菜叶分开，豆腐切块，生姜切片，小葱切葱花  
2、锅中加入少许油，放入姜片炒香，加入白菜帮翻炒至略软  
3、倒入清水，烧开后放入豆腐，小火煮5分钟  
4、加入白菜叶，继续煮5分钟  
5、加入盐和白胡椒粉，淋入香油，撒上葱花后出锅
