---
title: "肉骨茶"
---

| 主料   |
| :----- | -----: |
| 猪肋排 | 1000克 |

| 辅料 |
| :--- | ----: |
| 大蒜 | 100克 |

| 香料     |
| :------- | ---: |
| 白胡椒粒 | 25克 |
| 黑胡椒粒 |  3克 |
| 八角     |  1克 |
| 桂皮     |  1克 |

| 调料 |
| :--- | -----: |
| 清水 | 2000克 |
| 盐   |   10克 |
| 白糖 |    3克 |

| 蘸水   |
| :----- | ---: |
| 老抽   |  3克 |
| 生抽   | 20克 |
| 白糖   |  3克 |
| 清水   |  5克 |
| 小米辣 |  5克 |
| 大蒜   |  5克 |

制作过程：  
1、猪肋排剁成段，辅料中的大蒜剥去外层干皮并保留整头，蘸水中的大蒜切末，小米辣切圈  
2、八角和桂皮小火炒30秒，加入白胡椒粒和黑胡椒粒继续炒香，将胡椒粒稍微压碎后与八角、桂皮一同装入香料袋  
3、猪肋排冷水下锅，水开后煮5分钟，捞出冲洗干净  
4、锅中加入清水，烧开后放入猪肋排、大蒜和香料袋  
5、大火煮10分钟，撇去浮沫后转小火，加盖煮90分钟  
6、取出香料袋，加入盐和白糖，继续煮10分钟后出锅  
7、将老抽、生抽、白糖和清水搅拌至白糖溶解，加入小米辣和蒜末
