---
title: "法式洋葱汤"
---

| 主料     |
| :------- | ----: |
| 黄洋葱   | 500克 |
| 牛肉褐汤 | 800克 |

| 辅料 |
| :--- | ---: |
| 大蒜 |  5克 |

| 调料       |
| :--------- | ----: |
| 干白葡萄酒 | 100克 |
| 黄油       |  30克 |
| 面粉       |  10克 |
| 百里香     |   1克 |
| 香叶       |   1片 |
| 盐         |   3克 |
| 黑胡椒碎   | 0.5克 |

制作过程：  
1、洋葱切成细丝，大蒜切末  
2、锅中加入黄油，中火融化后放入洋葱和1克盐，翻炒10分钟至洋葱变软并析出水分  
3、转中小火继续炒25～40分钟，其间不时翻动，锅底出现褐色焦化物时加入少量清水刮起，重复2～3次，直至洋葱呈深金黄色  
4、加入蒜末炒香，再加入面粉翻炒1分钟  
5、倒入葡萄酒，刮起锅底焦化物，中火煮至酒液剩余约一半  
6、加入牛肉褐汤、百里香和香叶，烧开后转小火，锅盖留缝煮25分钟  
7、取出香叶，加入剩余的盐和黑胡椒碎，搅拌均匀后出锅
