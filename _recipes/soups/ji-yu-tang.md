---
title: "鲫鱼汤"
---

| 主料 |
| :--- | -------------: |
| 鲫鱼 | 1条（约500克） |

| 辅料 |
| :--- | ---: |
| 生姜 | 10克 |
| 小葱 | 15克 |

| 调料     |
| :------- | -----: |
| 开水     | 1200克 |
| 白酒     |   10克 |
| 盐       |    6克 |
| 白胡椒粉 |  0.5克 |
| 白糖     |    1克 |

制作过程：  
1、鲫鱼去除鱼鳞、鱼鳃、内脏和腹腔黑膜，清洗干净后在鱼身两侧切斜刀，用厨房纸吸干水分  
2、生姜切片，小葱打结  
3、锅中加入适量油，烧热后放入鲫鱼，中火煎至两面金黄  
4、沿锅边淋入白酒，加入姜片、葱结和开水，大火烧开  
5、保持大火煮10分钟，待汤色变白后转中火继续煮15分钟  
6、取出葱结和姜片，加入盐、白胡椒粉和白糖，搅拌均匀后出锅
