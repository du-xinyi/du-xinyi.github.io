---
title: "普罗旺斯炖鹿肉"
---

| 主料 |
| :--- | ----: |
| 鹿腩 | 500克 |

| 辅料     |
| :------- | ------: |
| 黄洋葱   |    半个 |
| 大蒜     |     4瓣 |
| 胡萝卜   |     1根 |
| 茴香头   |    半个 |
| 番茄罐头 |   400克 |
| 橄榄     |     2勺 |
| 白葡萄酒 | 500毫升 |
| 橙子皮   |    半个 |

| 调料     |
| :------- | ---: |
| 黄油     | 15克 |
| 橄榄油   | 15克 |
| 盐       |  3克 |
| 黑胡椒粉 |  1克 |
| 欧芹     |  5克 |

| 香料   |
| :----- | ----: |
| 桂皮   |   3克 |
| 丁香   | 0.3克 |
| 香叶   |   2片 |
| 迷迭香 |   1克 |
| 百里香 |   1克 |

制作过程：  
1、鹿腩洗净切块，沥干水分后撒上一半盐和黑胡椒粉  
2、洋葱切块，大蒜切片，胡萝卜和茴香头切稍大的块  
3、珐琅锅中加入一半橄榄油和黄油，将鹿肉煎至两面焦香后盛出  
4、锅中加入剩余的橄榄油和黄油，放入洋葱、大蒜、胡萝卜和茴香头，中小火翻炒至蔬菜变软  
5、倒入葡萄酒，大火烧开，加入番茄  
6、加入剩余的盐和黑胡椒粉调味  
7、加入煎好的鹿肉，放入香料、橙子皮、橄榄，加盖，小火炖2小时  
8、出锅前30分钟，夹出香料，出锅后撒上欧芹碎
