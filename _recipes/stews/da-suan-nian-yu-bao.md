---
title: "大蒜鲶鱼煲"
---

| 主料   |
| :----- | -----: |
| 鲶鱼   | 1500克 |
| 独头蒜 |  500克 |
| 老豆腐 |  400克 |
| 茄子   |  300克 |

| 辅料   |
| :----- | ----: |
| 啤酒   | 500克 |
| 酸菜杆 |  50克 |
| 红泡椒 |  30克 |
| 二荆条 |  30克 |
| 泡姜   |  20克 |
| 藿香   |  10克 |

| 腌料     |
| :------- | ---: |
| 鸡蛋     |  1个 |
| 玉米淀粉 | 50克 |
| 盐       |  3克 |
| 白胡椒粉 |  1克 |

| 调料   |
| :----- | ---: |
| 豆瓣酱 | 10克 |
| 花椒   |  3克 |
| 生抽   | 15克 |
| 香醋   |  5克 |
| 味精   |  2克 |

制作过程：  
1、鲶鱼剁成块，加入一半啤酒和少量盐抓洗，再用清水冲洗干净并沥干  
2、鱼块加入腌料抓拌均匀，腌制10分钟  
3、大蒜去皮后对半切开，酸菜、红泡椒、二荆条和泡姜切碎，豆腐和茄子切片  
4、砂锅中加入适量油，放入大蒜，小火煎至金黄  
5、另起锅加入适量油，将豆腐和茄子分别煎至两面微黄后盛出  
6、锅中加入适量油，放入鱼块，煎至两面微黄后放入砂锅，将豆腐码在鱼块上  
7、锅中留少许底油，放入花椒、酸菜和红泡椒炒香，再加入豆瓣酱炒出红油  
8、倒入剩余的啤酒，加入生抽、香醋、味精和白胡椒粉，烧开后倒入砂锅  
9、砂锅加盖，烧开后转小火焖15分钟  
10、加入茄子、二荆条和泡姜，轻轻翻匀后继续焖3分钟  
11、撒上藿香后出锅
