---
title: "腌笃鲜"
---

| 主料 |
| :--- | -----: |
| 春笋 |  500克 |
| 咸肉 |  300克 |
| 排骨 |  300克 |
| 百叶 |  150克 |
| 清水 | 2000克 |

| 辅料 |
| :--- | ---: |
| 小葱 | 15克 |
| 生姜 | 10克 |
| 大米 | 适量 |

| 调料   |
| :----- | ---: |
| 猪油   | 15克 |
| 花雕酒 | 15克 |
| 盐     | 适量 |

制作过程：  
1、春笋去皮后切滚刀块，咸肉切片，排骨剁段，百叶切条后打结，小葱打结，生姜切片  
2、春笋加入少许大米焯水后过凉，百叶焯水，咸肉和排骨冷水下锅焯水  
3、砂锅中加入猪油，放入咸肉和排骨煎至表面微黄，倒入烧开的清水  
4、加入葱结、生姜和花雕酒，烧开后转小火炖60分钟  
5、加入春笋和百叶结，继续小火炖20分钟  
6、取出葱结和生姜，根据咸度酌情加盐后出锅

P.S.  
1、咸肉本身含盐，出锅前试味后再决定是否加盐
