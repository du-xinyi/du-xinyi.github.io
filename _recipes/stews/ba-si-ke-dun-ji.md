---
title: "巴斯克炖鸡"
---

| 主料     |
| :------- | ----: |
| 带骨鸡腿 | 600克 |

| 辅料   |
| :----- | ----: |
| 番茄   | 400克 |
| 红甜椒 | 150克 |
| 青椒   | 100克 |
| 洋葱   | 150克 |
| 大蒜   |  15克 |

| 调料             |
| :--------------- | ----: |
| 干白葡萄酒       | 100克 |
| 盐               |   5克 |
| 黑胡椒碎         | 0.5克 |
| 埃斯佩莱特辣椒粉 |   2克 |
| 百里香           |   2枝 |
| 香叶             |   1片 |
| 橄榄油           |  适量 |

制作过程：  
1、鸡腿剁成大块，擦干表面水分，加入2克盐和黑胡椒碎，抓匀后腌制15分钟  
2、番茄去皮切碎，红甜椒和青椒去蒂去籽后切条，洋葱切丝，大蒜切末  
3、锅中加入适量橄榄油，放入鸡块，鸡皮朝下，中火煎至金黄，翻面煎至上色后盛出  
4、锅中留适量底油，放入洋葱炒软，加入红甜椒和青椒，继续翻炒5分钟，再加入蒜末炒香  
5、倒入白葡萄酒，刮起锅底焦化物，中火煮至酒液剩余约一半  
6、加入番茄、百里香、香叶、剩余的盐和一半辣椒粉，翻炒均匀后小火煮5分钟  
7、放回鸡块，加盖小火炖煮25～35分钟，至鸡肉熟透软嫩，其间汤汁过少时补适量水  
8、揭盖收至汤汁略微浓稠，取出百里香和香叶，撒入剩余的辣椒粉，轻轻拌匀后出锅

P.S.  
1、埃斯佩莱特辣椒粉可用甜椒粉搭配少量普通辣椒粉代替，风味会有所不同
