---
title: "老妈蹄花"
---

| 主料 |
| :--- | --------------: |
| 猪蹄 | 3个（约1500克） |
| 雪豆 |           150克 |
| 猪油 |            20克 |

| 炖料     |
| :------- | ----: |
| 料酒     |  20克 |
| 白芷     |   1克 |
| 生姜     |  20克 |
| 小葱     |  10克 |
| 花椒     |   2克 |
| 盐       |   4克 |
| 白胡椒粉 | 0.5克 |

| 蘸水   |
| :----- | ---: |
| 小米辣 | 10克 |
| 大蒜   | 10克 |
| 生姜   |  5克 |
| 小葱   | 10克 |
| 生抽   |  3克 |
| 香醋   |  1克 |
| 香油   |  4克 |
| 花椒油 |  2克 |
| 盐     |  1克 |
| 味精   |  1克 |
| 胡椒粉 | 少许 |

制作过程：  
1、猪蹄表面烧黄后洗净，从中间剁开，清水浸泡4小时  
2、雪豆开水浸泡4小时  
3、蘸水中的小米辣、大蒜和生姜切末，小葱切花；炖料中的生姜切片，小葱一半打结、一半切葱花  
4、猪蹄冷水下锅，加入葱结、一半姜片和料酒，大火烧开，撇去浮沫后煮10分钟  
5、另起锅加入清水、剩余的姜片、花椒和猪油，大火烧开，再放入猪蹄和白芷，中火煮1小时，加入雪豆继续煮50分钟  
6、加入盐，继续煮40分钟后捞出白芷和生姜  
7、加入白胡椒粉，大火稍收汤汁，保留大部分汤后出锅，撒上炖料中的葱花；蘸水中的所有材料混合，加入少许原汤搅拌均匀
